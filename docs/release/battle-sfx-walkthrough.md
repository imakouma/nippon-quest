# バトル効果音 Walkthrough

## 変更

攻撃の振り音・通常ヒット・強ヒット・被ダメージ・回復の5音源を、Stable Audio 3 Small SFXで無料ローカル生成した。既存の音名とSceneの演出タイミングを再利用し、戦闘数値・進行・教材・契約・依存は変更していない。200–650ms、モノラル44.1kHz MP3、5音源合計30,728 bytes。生成条件とハッシュは `assets/audio/se/battle-generation.json`、ライセンス証拠と権利台帳も登録済み。

戦闘開始時に5音源だけを準備してキャッシュする。探索の6音源は独立のまま。未読込・欠損時には以前の合成音で即時再生し、後から同じ音を二重再生しない。既存SE音量・ミュートに従う。
