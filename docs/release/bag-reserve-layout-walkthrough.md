# バッグの控え・持ち物を右側へ表示

## 変更

- 左側は配置マス、右側は「ひかえと もちもの」の常設一覧とする。
- 最初は詳細を閉じて一覧を広く表示し、選択時は一覧の下に詳細を開く。同じアイコンを再度押すと閉じる。
- 一覧は3列・上詰めとし、長い名前は単語の途中で切れにくくする。詳細表示中も一覧と配置マスを操作できる。
- 既存のドット絵、字体、配色を維持。保存形式・バッグの容量・装備条件は変更しない。

## 検証

- 変更前のE2Eで一覧が左側（x=40）にあり、右側配置の検査（x≥448）が失敗することを確認。
- 幅320・640・768・960・1024・1440pxで右側配置、一覧の高さ、カードの見切れを検査。
- 主人公と持ち物の詳細開閉、空の一覧、武器のドラッグ装備・移動、セーブ再開を検査。
- Enter/Spaceもクリックと同じ詳細開閉に統一。初期状態でEnterを押しても詳細が開かない失敗を再現してから修正。
- `pnpm lint`、`pnpm check:architecture`、`pnpm test`（1232件）、`pnpm validate:content`、`pnpm build`。
- 実画面の確認画像は、バッグE2Eの `test-results/…/reserve-right.png` と `weapon-moved.png` に出力する（Git管理外）。

## 残課題

- 全E2E一式ではなく、変更に関連するバッグ操作と進行の2本を実行する。
- GitHubへのpushとmainへの反映は、この変更を確認してから別途行う。
