# 技の必要ゲージ表示 — Walkthrough

## 変更

技一覧の「現在値/必要量」を「必要量」だけに変更。バーは手持ち量ではなく、対象教科の最大ゲージに対する必要量を示す（最大100なら必要100で全幅、必要50で半分）。最大量は既存のHUD表示モデルから取得する。

技行の右側を108pxの共通幅にし、通常技の「チャージ」と必殺技の「バー＋数値」で、属性アイコンとその右の表示開始位置を揃えた。主人公欄の現在ゲージ、チャージ量、使用条件、実際の消費量は変更していない。依存・教材仕様・契約の変更なし。

読み上げも「ひつようゲージ {cost}」に変更。既存の使用不可色テストは新しい表記に更新し、ポインタが非活性行へ重なって選択色になる揺れを避けるため、使用可能な行へhoverしてから通常色を検査する。

## 検証

- RED: 数値変更前は期待100に対して0/100で失敗。追加要求の再現では必要100でも塗りが0、丸アイコンと横の表示が通常技から20pxずれることをE2Eで確認。
- GREEN: 正規4174のE2E 4件成功。960×540・640×360、必要量100、検査用に50へ差し替えたケース、既存の使用不可表示を確認。
- ゲージの塗り比率、行内のアイコン・表示開始座標、必要量のみの数値、aria-label、使用不可判定、通常技のチャージ表示、ブラウザ例外なしを検査。
- 50のケースはブラウザへのJSON応答だけを置換し、実際の技能データは変更しない。
- 正規側: lint、単体112ファイル/1,221テスト、教材検証、TypeScriptを含むbuildが成功。
- 担当ブランチ: 変更対象のeslint/prettier、TypeScript、差分検査、構成検査が成功。
- 正規側の構成検査のみ既存の行数超過で失敗: Battle.ts 1,751行（上限1,750）、Overworld.ts 3,494行（上限3,490）。今回これらのSceneは変更していない。
