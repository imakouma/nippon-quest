# バトルの選択表示とキー操作

## 対象と表示方針

基点は `9ab858e4`、専用worktreeの `codex/main-battle-audio` で作業する。
確認は4175だけで行い、4174と別チャットの作業ツリーには触れない。

小学生向けの既存バトル画面を参照先とし、Referoの既存UI向け手順と
同梱のfocus・scrollガイドを使用する。外部アカウントや有料調査は使わない。

| 判断 | 参照・理由 |
| --- | --- |
| ドット絵・白い太枠・PixelMplus・配置を維持 | 既存バトルと前回承認済みの画面。今回は操作の修正に限定 |
| 黄色は現在の選択だけを表す | 既存の選択色とReferoの可視フォーカス方針。Tab・矢印・マウスの表示先を一致させる |
| 説明欄は読む場所として扱う | 既存の独立した説明欄。スクロール操作を道具の使用に誤解釈しない |

戦闘ロジック、教材、セーブ、依存、契約、生成元データは変更しない。

## 再現と修正

- Tabで次の項目へフォーカスを移しても、選択色・矢印移動の起点・Zキーの操作先が前の項目のままだった。フォーカス取得時も既存の選択位置へ同期する。
- 同じ問題を戦闘後の仲間加入の「はい／いいえ」でも回帰E2Eで確認し、同様に同期する。
- マウスを静止させたまま矢印で移動すると、hover行と選択行の両方が黄色になった。戦闘内だけ、非選択行のhover色を通常色に戻す。
- 道具の説明欄でEnterを押すと道具が使用された。説明欄のキー操作をメニューの決定へ伝播させず、戻る操作は維持する。ブラウザ標準のスクロール・Tab移動は妨げない。

最初に回帰E2Eを追加し、修正前に上記3件がそれぞれ意図したアサーションで失敗することを確認した。
証跡は `/private/tmp/nihon-quest-focus-red/` に保存（Git管理外）。
