# 東北版 Go / No-Go 判定

**判定: NO-GO**  
判定日: 2026-10-05 JST

## 公開を止める条件

- 教材レビュー待ち: 44ファイル・4,117問。
- 教材の承認記録: 0件。
- 要件基準の dated-fact 12件・visual-context 18件に対し、現行レビューキューの集計は変動事実候補8ファイル・視覚問題17ファイル。定義または母集団の差を解消し、再承認する必要がある。
- 東北6県の静的素材差し替え待ち: 86件（青森19、岩手14、宮城13、秋田13、山形13、福島14）。
- 素材権利台帳の統合監査では、配布対象1,560件中1,558件が権利確認保留。
- `pnpm check` と全E2E 22件はローカルの同一作業ツリーで成功済みだが、remote CIは未実施。

## 統合検証結果

- `pnpm check`: PASS（46ファイル・602テスト、content error 0、教材監査、知識グラフ、型検査、production buildを含む）
- 全E2E: PASS（22/22、production build使用、5分24秒）
- 地方別MVP E2E: PASS（甲信越・小2・算数・新潟開始、横向きタッチで地方・学年・相棒・開始ボタンへ到達）
- 東北通し: PASS（地方ボス撃破、バッグ拡張、保存、再読込、北海道結界）
- 教材専用監査: PASS。ただし東北18問を含む公開教材は人間承認待ち。
- 素材権利監査: PASS。ただし未確認素材を検出した結果として判定はNO-GO。

## GOに変更できる条件

1. 公開対象教材すべてに、担当者・確認日・一次資料・内容ハッシュを含む有効な承認記録がある。
2. 公開対象素材すべてに出典・ライセンス・利用条件の追跡記録があり、権利不明が0件。
3. `pnpm check` と全E2Eが統合コミット上で成功する。
4. 東北6県の進行、地方ボス、章末、保存、再読込、北海道結界を実ブラウザで確認する。
5. CIの必須チェックがすべて成功し、失敗を単なる再実行で隠していない。
6. dated-fact 12件・visual-context 18件という受入基準と、生成台帳の母集団・数え方を一致させる。

QA単独では教材承認・権利許諾を代行しない。上記が満たされるまでNO-GOを維持する。
