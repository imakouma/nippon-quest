# 東北版 Go / No-Go 判定

**判定: NO-GO**  
判定日: 2026-10-03 JST

## 公開を止める条件

- 教材レビュー待ち: 44ファイル・4,117問。
- 教材の承認記録: 0件。
- 東北6県の静的素材差し替え待ち: 86件（青森19、岩手14、宮城13、秋田13、山形13、福島14）。
- 素材の権利台帳は担当ブランチとの統合待ち。公開可を証明できない素材は権利不明として扱う。
- 統合後の `pnpm check`、全E2E、実ブラウザ通し確認が未実施。

## GOに変更できる条件

1. 公開対象教材すべてに、担当者・確認日・一次資料・内容ハッシュを含む有効な承認記録がある。
2. 公開対象素材すべてに出典・ライセンス・利用条件の追跡記録があり、権利不明が0件。
3. `pnpm check` と全E2Eが統合コミット上で成功する。
4. 東北6県の進行、地方ボス、章末、保存、再読込、北海道結界を実ブラウザで確認する。
5. CIの必須チェックがすべて成功し、失敗を単なる再実行で隠していない。

QA単独では教材承認・権利許諾を代行しない。上記が満たされるまでNO-GOを維持する。
