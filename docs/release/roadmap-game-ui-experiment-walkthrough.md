# 分岐・合流型の学習スキルツリー Walkthrough

## 何を作ったか

- 基礎単元を下、発展単元を上へ置く決定論的な縦型レイアウトへ変更した。
- 長文カードではなく48px以上の操作領域を持つ円形オーブを中心にし、通常時の名称・学年・習熟ゲージを地図から外した。
- 前提線は実教材データだけから生成し、曲線や点線を使わない連続した直線へ変更した。
- 2〜3個の前提がある発展単元は、すべてを達成したときだけ解放する。ロック中も選択でき、詳細パネルで `0/3` と未達単元を確認できるが、学習開始ボタンは表示しない。
- 学年・学期フィルタの外側にある直接前提も文脈ノードとして残し、境界で接続線だけが消えないようにした。
- 20〜160%ズーム、ピンチ、トラックパッド移動、ドラッグ、現在地中央寄せを維持した。
- 小学1年の国語・算数、小学1〜2年の生活へ、出典と根拠を持つ分岐・合流を追加した。補助英語は根拠のないハードロックを作らず、次の教材監修バッチへ保留した。

## デザイン判断

- ユーザー提供画像から借りたのは「下から上へ進む主幹」「左右の分岐」「複数線の合流」「小さい円形ノード」という読み方だけで、番号・固有アイコン・画面構成は複製していない。
- Referoの情報階層とタッチ操作の原則を使い、地図は構造、下部パネルは文字情報という役割に分けた。
- 状態は色だけでなく、記号、発光、文言、条件数を併用している。

## どう確認したか

- Unit 130ファイル・1409件、ロードマップE2E 1件、lint、architecture、content、curriculum graph、production buildを通した。
- AND条件を一時的に `every` から `some` へ変えるミューテーション確認で、追加した回帰テストが実際に失敗することを確認した後、元へ戻して再度合格させた。
- Playwright出力に `learning-roadmap-locked-condition.png`、`learning-roadmap-controls.png`、`learning-roadmap-20-percent.png` を保存した。
- アプリ内ブラウザで100%・20%、960×540・640×540を確認し、ノード、操作部品、条件パネルの重なりがないことを確認した。
- 低学年監査は、参照切れ0、重複0、教科横断ハードロック0、逆学年線0、単元循環0。生活は孤立0、算数と国語の未接続単元は全学年展開の教材作業として残している。
