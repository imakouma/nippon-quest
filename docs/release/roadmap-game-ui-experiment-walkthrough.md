# ゲームらしい学習マップ試作 Walkthrough

## 何を作ったか

- 現在の単元を、通常ノードより大きい発光拠点として表示する。
- 選択中の単元を黄色いダイヤ枠と強調経路で示す。
- 単元を押すと画面下部のクエストパネルへ詳細を出し、`ここを 学[まな]ぶ` を押したときだけ問題を開始する。
- 学年・習熟度・現在／復習／クリア状態をクエストパネルへ集約する。
- 50%未満では単元名、学年タグ、習熟ゲージを隠し、経路と拠点を見渡す俯瞰表示へ切り替える。
- 学ぶ時期バーをピクセルUIに合わせ、上部フィルタとズーム操作の視覚的な強さを下げる。

## どう確認したか

- `tests/unit/roadmapMenu.test.ts` で、選択だけでは開始しないこと、主要ボタンで開始すること、現在地の初期選択、20%俯瞰状態を確認した。
- `tests/e2e/progress.spec.ts` で、新規ゲームから学習マップを開き、選択パネル、20%俯瞰、100%復帰、パン、ピンチ、現在地中央寄せを確認した。
- Playwright出力に `learning-roadmap-controls.png` と `learning-roadmap-20-percent.png` を保存し、960×540で目視確認した。
- アプリ内ブラウザでも同じ画面を開き、RubyText、操作対象、パネルの重なりを確認した。
