## 対象と判断

- 対象画面: タイトル、フィールドメニューの2Dロードマップ、戦闘、保護者画面
- 対象表示: 640×540、960×540
- 今回の判定: **条件付き合格**
- 公開判断を妨げるUI起因の既知クラッシュ: なし
- 残条件: 全E2E、支援技術による読み上げ確認、性能予算の合意はQA・リリース統合時に確認する

スクリーンショットはE2E実行時に `/tmp/nihonquest-*.png` へ保存し、目視でクリッピングと隣接UIを確認した。

### アクセシビリティ

基準監査で、タイトルの視覚カーソルとDOMフォーカスが初回ロード時に一致しない場合があり、メニューと保護者画面がモーダルとして支援技術へ通知されず、Tab移動が背面へ抜ける問題を確認した。

改善後:

- タイトルの現在項目へDOMフォーカスを同期
- タイトルメニューへ名前を付与し、案内文を `aria-live="polite"` に設定
- メニューと保護者画面に `role="dialog"`、`aria-modal="true"`、見出し参照を追加
- モーダル表示時の初期フォーカス、Tab循環、閉じた後のフォーカス復帰を共通化
- フォーカス管理をChromium E2Eで回帰検証
