# 場面別BGM 実装結果

2026-10-12、承認済み `SPEC-game-music-system.md` の全9音源を実装した。

## 場面と音源

タイトル、フィールド、町、ダンジョン、秘密エリア、通常戦、ボス戦にループ曲を配置した。勝利・敗北は一回再生のジングルに切り替わる。会話・問題・施設・一時メニューは現在の曲を継続する。

通常戦闘曲を再利用し、8音源をStable Audio 3 Small Musicの公式MLX実装でMac上に生成した。追加API料金は0円。モデルはリポジトリ外に配置している。生成条件・シード・音圧調整・ハッシュは `assets/audio/bgm/generation.json` と `PROVENANCE.md` に記録した。

新しいループ曲の終端無音を取り除き、先頭と末尾を0.25秒重ねてループ境界を接続した。全音源は44.1kHzステレオ、192kbps MP3。合計約12.4MB。

## 再生制御

音楽セッションの最上位だけを再生する。戦闘中は探索曲を一時停止し、終了時に中断位置から再開する。同曲のマップ移動で先頭へ戻さない。曲変更は短いフェードでつなぐ。設定音量は進行中のSceneへ同期され、0から音量を上げる場合も再生できる。自動再生拒否は次の操作で再試行する。

## 残課題

音源の聴感や曲の好みに関する最終判断は試聴で行う。機械検査と再生検査は音楽的な好みを判定しない。開発サーバーではJSONのmodule importがJSON MIMEで配信される既存問題を検出したため、本番プレビューで検証した。

BGMは `imakouma/main` の `2166479` を基点とする専用ブランチ `codex/game-music` に切り分けた。共有作業ツリーの教材・画面変更は含めず、音源、音楽管理、Sceneへの接続、テスト、権利記録だけを管理する。

専用ブランチでも全1128テスト、構造検査、コンテンツ検証、ビルド、実ブラウザのBGM検査が成功した。全体lintは基点に元からある8ファイルのPrettier違反で失敗する。該当ファイルに今回の差分がないことを確認し、BGM変更ファイルのeslint・Prettierを個別に検査した。共有作業ツリーでの1200テスト成功は上記の統合状態に対する記録である。
