# 東北版 素材・権利・音 台帳

判定日: 2026-10-03

機械台帳: `assets/rights/tohoku-release-ledger.json`

再生成: `pnpm exec tsx scripts/audit-tohoku-assets-rights.ts --write`

## 公開判定

**NO-GO**。現在のVite設定は `assets/` 全体を `dist/assets/` へコピーする。ゲーム中に参照しないファイルも配布対象になるため、原典・作者・ライセンスが確認できない旧版問題画像を残したまま公開できない。

## 音の安全な挙動

音声ファイルは現時点で0件。英語問題の音声再生に失敗した場合は Web Speech API の `ctx.speak` へフォールバックする。BGM/SEを権利不明素材で埋めない。音声なしでも問題文と選択肢は表示され、回答は可能。

## 静的素材がない場合の表示

県モチーフ、NPC、肖像はTypeScript/Phaserで生成するフォールバックがある。静的差し替えの欠落自体は進行不能ではないが、生成コードの著作者と公開権限はリリース前に人間が確認する。

## 機械監査の保証範囲

- 配布対象の画像・音・フォントが台帳のちょうど1グループに属する。
- 承認済みフォントの存在、ライセンス証拠、SHA-256を検証する。
- 公開問題からの画像・音声参照について欠落を検出する。
- 東北6県の静的差し替え欠落数を再計算する。
- 音声ファイル数とWeb Speechフォールバックの存在を確認する。
- `hold` が1件でも配布物に含まれる場合は `NO-GO` とする。

監査成功は権利承認を意味しない。監査が成功したまま `NO-GO` になるのは、未確認素材を正しく検出できているためである。

## 人間にしか解除できないブロッカー

1. 旧版画像ごとの原典、作者、入手日、ライセンス、改変可否、再配布可否の確定。
2. 初回コミット由来画像とfaviconの制作者による権利表明。
3. 手続き生成PNGの生成元コードについて、著作者とプロジェクトの公開権限を確定。
4. 必要なBGM/SEを追加する場合のライセンス証拠とクレジット条件の登録。

公開物から未確認素材を除外する方式を選ぶ場合も、ビルド成果物を展開して再監査し、`assets/` の一括コピーにより再混入していないことを確認する。
