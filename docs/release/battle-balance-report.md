# 文理戦闘バランス監査

`pnpm audit:battle-balance` は導入コミット直前 `de57236^` の旧6能力JSON・旧計算式を基準に、現行の全542体を固定シードで比較する。Lv1・5・10・20・35・50（ボスのLv1のみ除外）について、通常攻撃と初期技の perfect / average / miss を計算し、計12,400シナリオを `tests/fixtures/battle-balance-before.json` と `tests/fixtures/battle-balance-after.json` に記録する。

敵HP÷与ダメージと主人公HP÷被ダメージから連続値の戦闘圧を求め、ボス区分・レベル・回答条件ごとの中央値を比較する。旧版からの圧力差は±35%、逃走率差は±0.10を許容範囲とし、超過時は条件を出力して非0終了する。現行データの範囲外は0件。

今回の調整は主人公・敵・装備を同じ縮尺で縮小し、相対的な強さを保ったまま初期表示を小さくした。Lv5・Lv10の節目成長、問題不正解時も進行できる0.55倍と最低1ダメージ、85〜100%の決定論的乱数を自動テストで固定している。
