# 第8章 中国地方編 — 五つの証言

## 章の役割

近畿で「観測者K」の本名が主人公の姉・カナエだと判明した直後の章。
名前や家族関係だけで有罪・無罪を決めず、同じ一日について語られた五つの証言を、時刻・場所・観測範囲・物証と照合する。

学びの核は次の三点。

1. 証言の食い違いは、直ちに嘘を意味しない。
2. 「見えなかった」と「存在しなかった」を分ける。
3. 人の目的、行動、結果を分け、あとから検証できる形で記録する。

## 県ごとの証言

| 県 | 手がかり | 調査すること |
| --- | --- | --- |
| 鳥取 | 砂丘の足跡 | 風紋との上下関係から前後を読む |
| 島根 | 湖上の船 | 証人の位置と見える範囲を地図にする |
| 岡山 | 橋の両端の目撃 | 時計のずれと移動可能時間を確かめる |
| 広島 | 三枚の手紙 | 紙・墨・筆跡から変更順と原文をたどる |
| 山口 | 洞窟のこだま | 反響を別人の証言として重複計上しない |

## 地方ボス

イツツノカタリベ。五つの証言から時刻と場所を奪い、食い違いを疑いへ変える仮面のワスレモノ。
戦闘前には「カナエ」という名前を罪の証拠にしようとするが、主人公は五つの視点を同じ一日へ戻して対抗する。

## 終幕と次章

五つの証言をつなぐと、カナエは壺を奪うためでなく、暴走直前に遮断装置へ走っていたことが分かる。
ただし、壺の流れを逆転させた操作記録にもカナエの名があるため、無実と断定しない。

四国編では「目的が正しければ、結果も正しいのか」を四つの天秤で問い、意図・手段・結果・責任を考える章へつなぐ。
