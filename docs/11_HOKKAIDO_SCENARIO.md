# 第二章「北海道のものさし」シナリオ

## 章の問い

北海道編では「大きさや距離を、一つの数字だけで決めてよいのか」を扱う。
地図上の距離、季節によって変わる移動時間、そこで暮らす人や生き物の声を重ね、
数字を現実の暮らしへ結び直す物語にする。

## 導入

東北地方ボスを浄化すると北の海に光の道が開き、北海道へ上陸できる。
シオリは東北の見聞帳に続く新しいページを持って同行する。
ミチルは北の空から自分を知る気配を感じ、主人公は記憶を他人の言葉だけで
決めず、自分たちで確かめると約束する。

## 攻略中の物語

- 札幌の町: 地図の距離・季節・移動時間という「三つのものさし」を提示する。
- 釧路湿原: 人間にとっての利用価値だけで土地を測らず、生態系のつながりを見る。
- 中ボス: 吹雪で消えた道を、天候と時間を含む地図として取り戻す。
- 県ボス: 距離・季節・暮らしを重ねた北海道のしるしを得る。
- クラーク博士: 一人の有名な言葉だけで歴史を代表させず、その前から続く声を聞く。

各節目で主人公、相棒、ミチル、シオリの見聞帳が反応し、攻略結果を物語へ戻す。

## 地方ボス

地方ボス「シロガネオオワシ」は、声が多ければ迷いが生まれると考え、
土地の記憶を一つの数字へ削って白地図にしていた存在である。
主人公たちは異なる声こそ土地の姿を見せると反論し、北海道の知識を解放する。

浄化後、シロガネオオワシはミチルもかつて日本地図を閉じようとしたと明かす。
主人公は過去の一場面だけで現在のミチルを決めず、全てを一緒に確かめると答える。
関東の結界から聞こえる教室の鐘を、第三章への導線として残す。
