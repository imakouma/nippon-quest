# ニホンクエスト（仮）— Antigravity 制作キット

小学生向け「ゲームが主体・勉強が要素」のドット絵 RPG を、Antigravity（Gemini / Claude）＋ ChatGPT（画像編集）で作るためのドキュメント一式です。

## 役割分担（想定）

| 役割 | 触るフォルダ | 使う道具 |
|---|---|---|
| ゲーム本体（あなた） | `src/core`, `src/scenes`, `docs/` | Antigravity（Plan: Gemini / 実装: Claude） |
| 問題UI担当 | `src/questions/renderers/` | Antigravity（Claude）、Playground |
| 問題作成者 | `content/questions/` | VS Code（スキーマ補完）、Playground、付録 B のプロンプト |
| 絵素材担当 | `assets/`, `raw/` | Gemini 画像生成、ChatGPT 画像編集、Aseprite/Piskel、後処理スクリプト |

三分割の境界（`01_ARCHITECTURE.md` §3）を守れば、4 人が同じ日に別々のフォルダで作業しても衝突しません。

## 他に必要なもの（ツール・素材・知識・手続き）

### ツール

| 用途 | 推奨 | 備考 |
|---|---|---|
| ドット絵の手直し | **Aseprite**（有料・買い切り）／無料なら **LibreSprite** か **Piskel**（ブラウザ） | AI 生成物の最終調整に必須。1 体 5〜10 分の手直しで見違える |
| マップ作成 | **Tiled**（無料） | Phaser と相性抜群。非エンジニアがマップを描ける |
| 画像一括処理 | Node `sharp`（03 §7 のスクリプト）、または ImageMagick | 縮小・減色・透過 |
| バージョン管理 | Git ＋ GitHub（private リポジトリ） | 問題作成者にも「GitHub Desktop で Pull → 編集 → Commit → Push」の 4 手順だけ覚えてもらう。または `content/` だけ Google Drive 同期でも可（MVP 中は） |
| 公開 | GitHub Pages か Cloudflare Pages（無料） | Vite の静的ビルドをそのまま置ける。ログイン無しなのでサーバー不要 |
| 音の編集 | Audacity（無料） | 英単語の録音・トリミング |

### フォント（ドット絵と相性のよい日本語フォント・無料）

- **PixelMplus**（10px/12px。M+ FONT LICENSE、商用可）— 定番。ルビにも使える。**PixelMplus12 を採用して同梱済み**（`src/ui/fonts/`。12 / 24 / 36 / 48px で使う）。
- **DotGothic16**（Google Fonts、SIL OFL）— Web で読み込みやすい。
- **美咲フォント**（8px）— 超小型。アイテム名など極小表示用。
- 使用時はライセンス表記をタイトル画面の「クレジット」に入れる。

### 音素材（無料・要規約確認）

- BGM：**魔王魂**、**DOVA-SYNDROME**、**甘茶の音楽工房**（いずれも利用規約とクレジット表記の条件を確認）。ドット絵に合わせるなら 8bit/チップチューン系タグで探す。
- 効果音：**効果音ラボ**、**Springin' Sound Stock**。
- 英単語音声：ネイティブ音声の無料素材は権利が曖昧なものが多いので、**Web Speech API（`en-US`）で MVP を回し、後で録音に差し替え**が現実的。
- 会話の読み上げ：Web Speech API の `ja-JP`（端末内蔵。iPad の Safari でも動く）。

### 学習内容の根拠資料

- **学習指導要領（文部科学省）** 小学校 各教科 — 単元と学年の割り当ての正。
- **学年別漢字配当表** — ふりがな制御と `kanji-trace` の出題範囲。JSON 化して `content/i18n/kanji-grades.json` に。
- 英語：小 3・4 は「外国語活動」（聞く・話す中心）、小 5・6 で教科化。**低学年の英語は絵と音のみ**、文字を読ませるのは小 3 以降に。
- 中学受験を意識するなら、社会（地理：都道府県・特産品・地形）と理科（実験・観察）が本ゲームの構造と最も相性がよい。算数は「速さ・割合」など高学年単元を `experiment`／`number-build` でどう遊びにするかが腕の見せどころ。

### 法務・安全（子ども向けプロダクトとして）

- **個人情報を取らない**（名前入力はニックネーム扱い、送信しない）。ログイン無しの設計はこの点で強い。将来オンライン対戦を足すときも「パーティ JSON の交換」だけにしてチャット機能を付けない。
- **画像生成 AI の利用規約**（商用利用可否、生成物の権利）を Gemini・ChatGPT それぞれ確認。学校配布や有償化を考えるなら特に。
- **ご当地キャラ（自治体マスコット）・企業ブランド・アニメキャラ** は絵にも名前にも使わない（`03` §9）。「りんご」「ねぶた」「なまはげ」など一般名詞・伝統文化は OK。
- **宗教施設** は敵にしない（`05` §4）。**歴史上の人物** は 2026-09-15 から そのまま登場させてよい（伊達政宗・源義経など。裏ステージのラスボス。`05` §7）。
- 学校で使うなら、アクセシビリティ（タッチのみ操作、色覚多様性への配慮、ふりがな）は「あると良い」ではなく必須要件と考える。

### プレイテスト

- 青森 1 県が通しで動いた時点で、**実際の小学生 3〜5 人に 15 分遊んでもらう**。見るのは (1) 説明なしで戦闘に入れるか (2) 「わざ」を選びたがるか（＝問題に自分から行くか） (3) 不正解のときの表情。
- 保護者メニューの習熟度グラフは、保護者が「買う理由」になる部分なので、早めに見せて反応を取る。

## 進め方の目安

- **週 1〜2 ステップ**のペースで、MVP（`00` §10 の完成定義）まで **8〜12 週間**。絵素材は並行して進める。
- 最初の 2 週間で Step 0〜2（基盤＋問題システム＋Playground）を終えると、問題作成者と UI 担当が動き出せる。ここを急ぐ価値が一番大きい。
- Antigravity が一気に作ろうとしたら止めて、1 ステップずつ。**docs を直してから頼む、Plan を読んでから承認する、Walkthrough を読んでから次へ**。この 3 つを守るだけで手戻りが半分になります。

## 迷ったときの原則（`00` §1 の再掲）

1. 問題を解くことがゲーム内の行動そのものになっているか
2. 不正解でもゲームは止まらないか（弱くなるだけ）
3. 小学生が説明書なしで触れるか
