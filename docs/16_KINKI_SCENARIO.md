# 第七章「近畿の六つの記録箱」シナリオ設計

## 章の役割

滋賀・京都・大阪・兵庫・奈良・和歌山をめぐり、分類と関係を同時に扱う章。
分類は探しやすくする入口であり、人物や出来事を閉じ込める壁ではないことを学ぶ。

## 流れ

1. 六つの書庫に分けられた記録から、箱をまたぐ参照線を取り戻す。
2. 日付・場所・人物など共通の手がかりで、複数分類の記録を結ぶ。
3. 地方ボス「ロッカギノオリ」を浄化し、六つの操作記録を重ねる。
4. 観測者 K の本名が「カナエ」で、主人公の姉だと判明する。
5. 家族という分類だけで判断せず、中国地方で本人と証言を探す。

## 次章への伏線

中国地方の五つの証言台が、同じ「あの日」を異なる視点で語り始める。
