# 旧 autonomy-game からの移行ルール

旧版には大量の教材資産がある一方、ゲーム状態・React UI・Convex・`localStorage` が密結合していた。
現在版へはコードを丸ごとコピーせず、データを検査可能な契約へ変換して移す。

## 絶対に守ること

1. 旧データを直接 `content/` にコピーしない。
2. まず `pnpm import:legacy-questions --source /path/to/autonomy-game` で隔離領域へ変換する。
3. `imports/legacy-questions/staged.json` は未レビューであり、ゲームから読み込まない。
4. 自動昇格では構造・参照・画像を検証する。教材内容の正しさを保証するには、別途人間が確認する。
5. レビュー記録へ問題の指紋と期待する正解を固定し、`pnpm promote:legacy-questions -- <review.json>` で昇格する。
6. `pnpm validate:content` と `pnpm test` が通らない状態では昇格しない。

## 自動検査で除外するもの

- 学年を確定できないノード
- 現在版にレンダラーがない回答形式
- 空の問題文・選択肢
- 正解番号が範囲外
- 同一選択肢は重複を畳み、正解位置を再計算できない場合は除外する
- 内容が完全に重複する問題
- 現在版の問題スキーマに適合しない問題

「下の図」「グラフ」「右から何番目」などを含む問題や旧画像参照は、最初に `reviewFlags` が付く。
画像をローカルへ検証保存するか、旧解説に残った数値から欠落図を安全に復元できた場合だけフラグを外す。
現在版では `choice`、`text-input`、`map-tap` として移行している。

## 昇格ゲート

- レビュー対象はノード単位ではなく、内容から作った `fingerprint` 単位。
- レビュー記録の `expectedAnswer` と実データの正解文字列が一致しなければ停止する。
- `provenanceConfirmed: true`、レビュー担当、日付がなければ停止する。
- 出力先は `content/questions/` 配下だけ。既存ファイルは上書きしない。
- 旧データが更新されて指紋が変わると停止するため、未確認の差し替えは入らない。

自動検査は「内容が学術的に正しい」ことまでは保証しない。画像なしでは成立しない問題、文章の不自然さ、
複数の正解が成り立つ問題、古い制度・統計などはレビューで除外する。

## 再発防止の設計

- 問題データは `content/questions/` のJSONに置き、ゲームロジックへ埋め込まない。
- 問題UIは `QuestionResult` だけをゲーム本体へ返す。
- セーブ形式は `src/core/state` に集約し、画面ごとの独自キーを増やさない。
- ゲームルールは `src/core` の純粋関数に置き、Phaser SceneやUIから分離する。
- 乱数はシード付きRNGだけを使う。
- 問題追加時は、スキーマ検証・ID重複・参照切れ・境界テストを必ず実行する。

## 現在の移行状況（2026-10-01）

- 旧版の問題総数: 5,209問
- 一意な問題として変換・昇格: 3,913問（22ファイル）
- 除外: 1,296問。すべて内容が完全一致する重複で、教材の欠落ではない
- 旧画像URL: 695件すべてローカル保存・検証済み
- 画像を使う問題: 859問をローカル画像参照へ更新、取得失敗0件
- 残存 `reviewFlags`: 0件
- 旧ロードマップ: 258単元を移行。既存単元を含む全体は293単元
- メニューの初期タブへ、既存の習熟度データを使う2Dロードマップを統合済み

`imports/legacy-questions/report.json` は初回ステージング時点の監査記録なので、そこに残るフラグ集計は
画像ローカライズ前の値である。最終結果は `image-report.json` と `content/questions/legacy/` を正とする。

構造検査、参照検査、全テスト、プロダクションビルドは通過している。ただし、自動検査だけで教材内容の
学術的な正しさを保証するものではない。今後の内容レビューは問題を削除せず、指紋単位の修正履歴として残す。
