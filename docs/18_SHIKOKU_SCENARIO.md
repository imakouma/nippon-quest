# 第9章 四国編 — 四つの天秤

## 章の役割

中国地方で、カナエが壺を奪うためでなく暴走を止めるために動いていたと判明した後の章。
善意だけで無罪とせず、悪い結果だけで悪人とも決めず、判断を四つの軸へ分ける。

1. 目的 — 何を守ろうとしたのか。
2. 手段 — 他に選べる方法と、それぞれの代償は何か。
3. 予測 — その時点で知りえた危険へ、どう備えたか。
4. 責任 — 起きた結果へ、その後どう向きあったか。

## 県ごとの天秤

| 県 | 判断の題材 | 学び |
| --- | --- | --- |
| 徳島 | 全員参加の祭り | 善い目的と本人の同意を両立する |
| 香川 | 水不足への取水 | 手段ごとの利益と代償を比べる |
| 愛媛 | 薬を運ぶ海路 | 予測できる危険と備えを判断へ入れる |
| 高知 | 予想外の嵐 | 結果の後に救助・修復・改善を選ぶ |

## 地方ボス

ヨツノテンビン。目的の皿だけを重く固定し、善意を免罪符へ変える石像のワスレモノ。
主人公は、善意を消さず免罪符にもせず、当時の情報・選んだ手段・結果・その後の行動をすべて量る。

## 終幕と最終章

カナエは主人公とミチルを逃がすため、危険を承知で知識を日本中へ放つ緊急操作を選んだ。
魔王はその流れを奪って忘却へ変えた。カナエの目的、選択の責任、魔王の加害を混同せず最終章へ持ち込む。

九州・沖縄では、魔王の城とそこへ向かうカナエが同時に現れ、集めた調査方法を総動員する最終章へ接続する。
