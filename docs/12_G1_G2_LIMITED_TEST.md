# 小学1・2年生向け 地方別教科MVP 要件

更新日: 2026-10-05

## 1. 今回つくるもの

対象は、保護者同伴で実施する限定テスト版とする。全国47都道府県は地図上で見られるが、完成章として開始・攻略できる地方は次の2つだけとする。

| 地方 | 完成範囲 | 主教科 | 開始地点 | 対象学年 |
|---|---|---|---|---|
| 東北 | 青森・岩手・宮城・秋田・山形・福島 | 国語・生活科 | 青森 | 小1・小2 |
| 甲信越 | 新潟・山梨・長野 | 算数（低学年） | 新潟 | 小1・小2 |

北陸・東海を含む残り38都道府県は、全国の広がりを伝えるプレビューとする。完成・公開済みとは表示しない。

## 2. 子どもに説明しないで確かめること

1. タイトルから「はじめから」を見つけられる。
2. 自分の学年、遊びたい地方、相棒を選べる。
3. 移動・会話・戦闘・問題回答を、口頭の操作説明なしで始められる。
4. 勉強画面へ切り替わったと感じて離脱せず、もう一度遊ぶ意思を示す。
5. 東北では6県の県ボスと地方ボスを倒し、章末まで到達できる。
6. 中断後に「つづきから」で同じ進行へ戻れる。

大人は安全確保と端末トラブル以外のヒントを出さない。詰まった場合は、場所、直前の表示、試した操作、経過時間を記録する。

## 3. 合否指標

- 操作理解: 最初の移動まで2分以内。主要操作で大人の説明0回を目標とする。
- 継続性: 15分後も自発的に継続、または「また遊びたい」と回答する。
- 学習受容: 問題を理由とする即時離脱がなく、誤答後も次の行動へ戻れる。
- 完走性: テスト補助用短縮セーブを用いる場合でも、東北6県、地方ボス、保存、再開を一連で完了する。
- 進行不能: 0件。画面外ボタン、閉じられない会話、出ない問題、保存上書き競合を含む。

観察人数が少ない段階では割合を「品質保証」と誤表現しない。個々の詰まりを再現テストへ変換し、修正後に同じ手順で再確認する。

## 4. 実装上の契約

- 選択学年が小1なら小1、小2なら小2の問題だけを優先する。技の範囲外では最も近い有効学年へ丸める。
- 東北限定相棒の得意教科は国語または生活科、甲信越限定相棒は算数とする。
- 地方選択は初期位置、初期技、相棒候補、出題テーマへ一貫して反映する。
- 新潟は本MVPでは甲信越に所属し、全国地図の地方シルエットも同じ定義から生成する。
- 既存セーブとの互換性のため、地方指定のない新規ゲーム生成は東北開始とする。

## 5. 公開判定

限定テスト実施可否と一般公開可否は分ける。ローカルの機能・自動テストが成功しても、教材承認または素材権利確認が未完なら一般公開は No-Go とする。現在の根拠と未達条件は `docs/release/TOHOKU_GO_NO_GO.md` を正とする。

## 6. 再現手順

```bash
pnpm validate:content
pnpm test
pnpm build
pnpm test:e2e
node scripts/qa-tohoku-release.mjs
```

最後の判定コマンドは未達条件がある間、意図的に終了コード2を返す。
