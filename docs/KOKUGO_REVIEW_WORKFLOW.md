# 国語問題の確認手順

## ゼミ生が行うこと

1. Google スプレッドシートの「国語問題チェック」を開く。
2. 管理IDを変えず、原文と「自動チェック（警告のみ）」を確認する。
3. 修正が必要な場合は「修正後」列に入力し、確認状態を「反映可」にする。
4. 問題がない場合は「問題なし」にする。判断できない場合は「要修正」のままメモを残す。

「自動チェック」は警告であり、誤りの断定や自動修正は行わない。

## 開発者が行うこと

```bash
# 現在の国語問題をCSVへ書き出す
pnpm kokugo:review:export

# Google Sheets の「国語問題チェック」タブだけをCSVでダウンロードし、事前確認する
pnpm kokugo:review:apply -- /path/to/review.csv

# 事前確認が成功した場合だけ反映する
pnpm kokugo:review:apply -- /path/to/review.csv --write

# 反映後の教材検査
pnpm validate:content
```

反映対象は「確認状態 = 反映可」の行だけである。元データが書き出し後に変わっていた場合は、問題文だけでなく正解・単元・payloadを含むハッシュ不一致で停止する。問題ID・正解・選択肢IDの追加、削除、変更はこの手順では行わない。
