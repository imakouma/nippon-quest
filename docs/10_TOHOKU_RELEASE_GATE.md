# 東北限定テスト リリースゲート

東北版の機能完成と一般公開の可否を混同しないための入口文書。詳細証拠は `docs/release/` の各台帳を参照する。

## GO条件

- unit 519件以上（現在の基準は602件以上）
- content validation error 0
- 全E2E成功、東北通しプレイ成功、進行不能0
- 東北素材不足0、権利不明素材0、性能予算合格
- 教材承認状況を実態どおり表示
- 公開対象44問題ファイル、dated-fact 12件、visual-context 18件の状態を台帳に明記
- 保存、再読込、「つづきから」による再開成功

教材承認が未完なら、ゲーム部分が完成していても一般公開は No-Go とする。No-Goは開発失敗ではなく、公開前に残る条件を具体化した判定である。

## 現在の判定

`docs/release/TOHOKU_GO_NO_GO.md` のとおり **No-Go**。主な理由は教材承認0件、東北静的素材不足、素材権利確認保留、remote CI未確認、および dated-fact / visual-context の要件値と現行集計の不一致である。ローカルCI相当検査はunit 602件、全E2E 22件を含め成功している。限定された保護者同伴テストは、個人情報を集めず、外部公開を行わない条件で別途実施可否を判断する。
