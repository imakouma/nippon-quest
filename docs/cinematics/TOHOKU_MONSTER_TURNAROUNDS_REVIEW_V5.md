# 追加20体：元ドットと4方向設定画（第4バッチ）

新規20体を追加。これまでと合わせて計60体分の4方向シートです。全国分は引き続き制作中。

左上＝正面／右上＝斜め／左下＝右向き側面／右下＝背面。各1536×1024。元ドットを基準に、丸くマットな3Dミニチュア調で制作しました。背面等の未描写部分は補完を含み、実3Dモデルではありません。ユーザー確認待ちです。

今回：青森1体・岩手6体・宮城12体・秋田1体。中ボス版ネブタイショウは既存の仲間版とは別の元ドットです。

ササカマブシは鉢巻の左右と焼き目、オオハクチョウは正面の向きを修正したv2を表示しています。ほか18体はv1。ゲーム内のドット絵や動作は変更していません。
