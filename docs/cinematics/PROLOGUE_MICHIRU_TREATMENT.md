# 映像脚本案: 目覚めとミチルとの出会い

Status: prototype completed / direction revision pending
Target: 16:9 / 約60秒 / 9カット / プリレンダー映像
Placement: 新規ゲームの外見・学年選択後、名前入力の直前

## 2026-10-14 試作レビューと次回の修正方針

現行試作はゲーム内へ一度組み込み、再生導線とピクセル画面への接続を確認する。ただし、映像表現の正式版としては確定しない。次回以降、以下の順序で方向性を再設計する。

### 1. ミチルの声

- 現行音声は男性的に聞こえるため不採用とする。
- 若い女性であることが明確に伝わる、柔らかく自然な日本語音声へ変更する。
- 高すぎるアニメ声や過度な幼児声にはせず、親しみやすさと案内役としての落ち着きを両立する。
- 全台詞を作り直す前に、代表台詞2本で複数の声を比較して採用音声を決める。

### 2. ミチルのキャラクターデザイン

- 現行デザインは発光、星、翼、金装飾、粒子が重なり、全体にキラキラしすぎている。
- 発光は羅針盤と必要な演出だけに限定し、常時の粒子、星の密度、金装飾を減らす。
- 翼は輪郭と枚数が読み取りやすい簡潔な形へ整理し、画面の主役を顔と演技に戻す。
- 衣装は装飾量を抑え、日本の旅・地図・土地の記憶を感じる素材や意匠へ寄せる。
- 現行の `model-sheet-v1.png` と `model-sheet-v2-candidate.png` は試作参照として保存する。
- 正式参照は、簡略3D案05を基にした `model-sheet-v3-approved.png` とする。

### 3. 世界観と背景

- 現行の一般的な幻想アニメ風の海辺は、想定している世界観と一致していないため正式採用しない。
- 次回は、時代感、地域、日本らしさ、自然と建築、魔法表現の強さ、色彩を先に言語化する。
- 背景を先に3案程度の静止画で比較し、世界観を決めてから人物と動画を再生成する。
- 高解像度映像であることは維持するが、豪華さや発光量を品質の代わりにしない。

### 4. 次回の確認手順

1. 現行試作をゲーム内へ仮組み込みし、再生開始、スキップ、終了後の名前入力への接続を確認する。
2. 世界観の短いデザインブリーフを作り、背景静止画3案から方向を選ぶ。
3. 装飾を抑えたミチルのモデルシートv2を作り、正面・側面・表情・配色を確認する。
4. 女性音声候補を代表台詞2本で比較し、正式な声を決める。
5. 承認した背景、モデル、声で10秒前後の試験映像を1本作る。
6. 試験映像の確認後にだけ、全9カットの正式版を制作する。

今回の動画生成物は比較用プロトタイプとして保持し、正式版の上書きや全編再生成は上記の方向性が決まるまで行わない。

## 映像の役割

- 高解像度のミチルを初めて見せ、ゲームの顔として記憶させる。
- 主人公とミチルが、ともに記憶を失っていることを伝える。
- 「知識が盗まれた国を旅する」という目的を短く示す。
- 主人公の容姿を固定せず、プレイヤーが選んだ外見との矛盾を避ける。
- 映像終了後の名前入力と、ピクセルRPGの開始へ自然につなぐ。

## 感情の流れ

1. **不安** — 見知らぬ場所で目覚める。
2. **驚き** — 小さな光からミチルが現れる。
3. **共感** — ミチルも記憶を失っている。
4. **危機** — 国から知識が奪われていると分かる。
5. **希望** — 二人で最初の町へ向かう。

## 試作時の継続アンカー

- ミチルは `assets/cinematics/characters/michiru/model-sheet-v3-approved.png` を正式参照とする。
- 顔、年齢、髪、4枚の幅広い翼、大きな二色マフラー、花びら形の一枚服、羅針盤ブローチを全カットで固定する。
- 主人公は主観視点、逆光の影、手元だけで表現し、顔・髪・服色を断定しない。
- 背景は青森の海と森を感じる夜明け前。固有の名所はまだ見せない。
- 色は深い藍色から朝の金色へ変化し、感情の回復を表す。

## ショットリスト

### Shot 1 — 風の音 / 0:00–0:05

- 真っ暗な画面。風、遠い波、草がこすれる音。
- 主観視点でゆっくり瞼が開くように明るくなる。
- 低い草の隙間から、夜明け前の空と揺れる木の枝が見える。
- カメラ: 地面すれすれの広角。わずかに呼吸で上下する。
- 台詞: 主人公（心の声）「……風の音がする。ここは、どこだろう？」

### Shot 2 — 失われた記憶 / 0:05–0:11

- 主人公が手を持ち上げる。手の輪郭には色を強く付けない。
- 一瞬だけ、白い教室、割れた地図、光る壺の断片がフラッシュする。
- どの断片も完全には見えず、すぐ白いノイズへ崩れる。
- カメラ: 手元への浅いフォーカス。記憶の瞬間だけ急速な切り返し。
- 台詞: 主人公（心の声）「名前は覚えている。でも……どうしてここに？」

### Shot 3 — 小さな灯 / 0:11–0:16

- 草むらの向こうに金色の光がひとつ灯る。
- 光は警戒するように止まり、主人公の周囲を半周する。
- 4枚の翼が光の中で一瞬だけ透けて見える。
- カメラ: 主観のまま、光を追う小さなパン。レンズに柔らかな光が入る。
- 台詞なし。

### Shot 4 — ミチル登場 / 0:16–0:24

- 光がほどけ、ミチルの全身が初めて現れる。
- ミチルは少し不安そうに主人公をのぞき込み、安心して微笑む。
- 翼の星座が順番に灯り、頭上の羅針盤の光が主人公を指す。
- カメラ: ミチルの全身が分かるミディアムから、顔へゆっくり寄る。
- 台詞: ミチル「やっと目を覚ましたね。……わたしの姿が見える？」

### Shot 5 — 同じ忘れもの / 0:24–0:32

- ミチルは名乗ろうとして一瞬言葉を止める。
- 胸元の羅針盤へ触れるが、針が定まらず静かに回っている。
- 笑顔を作るが、目にはわずかな寂しさが残る。
- カメラ: 胸元の羅針盤のインサートから、心配そうな顔へ切り返す。
- 台詞: ミチル「わたしはミチル。道を探す妖精……だったと思う。わたしも、大切なことを思い出せないの。」

### Shot 6 — 消える知識 / 0:32–0:41

- ミチルが空中に光の地図を開く。
- 地図上の町の名前、数字、文字、動植物の図が黒い霧に触れて消えていく。
- 遠くの森に、苦しむ獣の大きな影が一度だけ立ち上がる。
- 敵の正式デザインはまだ見せず、目と輪郭だけに留める。
- カメラ: 地図を回り込むオービットから、森の影へラックフォーカス。
- 台詞: ミチル「この国から、名前や数、歴史や暮らしの知識が盗まれているの。」

### Shot 7 — 手を伸ばす / 0:41–0:49

- 黒い霧に地図が飲まれかけるが、ミチルが両手で光を守る。
- 主人公の手が画面手前から伸び、ミチルの小さな手に触れる。
- 二人の間に金色と空色の光が走り、地図の一部が戻る。
- カメラ: 手と手の極端なクローズアップ。接触後、光とともに引く。
- 台詞: ミチル「思い出させれば、知識は土地へ戻るはず。いっしょに確かめに行こう。」

### Shot 8 — 最初の道 / 0:49–0:56

- 朝日が差し、森の先に小さな町へ続く道が見える。
- ミチルが先へ飛び、振り返って主人公を待つ。
- カメラ: 主人公の背後に近い位置から、道と朝日へゆっくり上昇する。
- 台詞: ミチル「まずは、近くの町へ。あなたの記憶の手がかりも、きっとそこにある。」

### Shot 9 — 名前を聞く / 0:56–1:02

- ミチルがカメラの近くまで戻り、少し照れたように首を傾げる。
- 背景の朝日と翼の光が重なり、画面を白く包む。
- カメラ: 顔のクローズアップ。最後は白へフェード。
- 台詞: ミチル「そういえば、あなたの名前をまだ聞いていなかったね。なんていうの？」
- 接続: 白背景から既存の名前入力UIを表示する。

## 音響方針

- 音楽: ピアノの単音と薄い弦から始め、ミチル登場で木管と小さなベルを加える。
- 環境音: 風、草、遠い波、鳥の最初の声。朝になるにつれて音数を増やす。
- ミチル: 翼に薄いガラス音、羅針盤の灯に柔らかなベル。常時鳴らさない。
- 黒い霧: 低い逆再生音。小学生を怖がらせすぎない音量と長さにする。
- 台詞: 最終版は日本語音声＋字幕を想定。試作段階は仮音声でもよい。

## 映像仕様

- 1920×1080 / 16:9 / 24fps を基準とする。
- 1ショットを3〜9秒で個別生成し、編集で接続する。
- ミチルの台詞を映像生成モデルへ直接しゃべらせず、映像完成後に音声と字幕を同期する。
- カメラ移動は1ショットにつき1種類に抑え、顔と指の破綻を優先して避ける。
- フラッシュは短く弱くし、光過敏への配慮として強い全画面点滅を使わない。

## 承認後の制作順

1. Shot 1〜9の静止画絵コンテを作る。
2. 絵コンテでミチルの同一性、主人公の非特定化、背景、カメラを確認する。
3. 各ショットの開始フレームを高品質で作る。
4. 3〜9秒の動画をショット単位で生成する。
5. 音楽、環境音、音声、字幕を編集する。
6. 完成動画をゲームへ組み込み、名前入力とピクセル画面への接続を検証する。
