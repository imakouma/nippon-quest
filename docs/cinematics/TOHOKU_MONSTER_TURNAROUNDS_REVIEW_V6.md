# 追加20体：元ドットと4方向設定画（第5バッチ）

新規20体を追加し、累計80体分。全国分は制作中です。

今回は秋田9体・山形10体・福島1体。内蔵画像生成で、元ドットを基準に丸くマットな3Dミニチュア調へ展開。ゲーム内のドットや動作は変更していません。

左上＝正面／右上＝斜め／左下＝右向き側面／右下＝背面。各1536×1024。双子のさくらんぼは両方を見せるため側面を少しずらしています。実3Dモデルや精密な正投影ではなく、側背面は補完を含む外観資料です。

修正版：ジャンボイモニv3（側面とおたまの側）、カントウマンv2（背面の竿燈の側）、サクランボーイv2（横向き）、キリタンポンv2（炎3山）、マゲワッパンv2（蓋のとじ目）。その他15体はv1。今回分はユーザー確認待ちです。
