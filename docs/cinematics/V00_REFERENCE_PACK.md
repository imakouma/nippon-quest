## なぜ先に作るか

V00は主要人物の出会い前の俯瞰映像なので、主人公・ミチル・シオリ・カナエ・御三家・魔王を新たに作り直す必要はない。必要なのは、複数コマに繰り返し出る住民、同じ町の配置、道具、通常種の同一個体を揃えること。これらを参照し、カット内で顔・服・建物・物の数が変わるのを抑える。

- 住民5人の全身と通常／困惑の表情、衣装の対応を確認。

- 小道具v1では、単体りんごは3個だが籠の中が2個だった。個数不一致として`07-everyday-props-sheet-v1-count-rejected.png`を履歴保存し、本制作参照には使わない。
- R07のv2は単体3個、左の籠0個、右の籠3個を目視確認済み。この3個は個数を明確に見せるための参照テストで、本編の問題や分配方法を確定しない。C03では台本の具体的な個数・分ける先・手の動きを決め、その配置を全コマで維持する。
- R08は顔・衣装・地面への接地・人物と店舗の縮尺が馴染むかのテストとして確認済み。ただし店の背景には大量のりんごがあるため、C03の数える対象・籠の配置をそのまま流用しない。
- ファイルが開けることと画像寸法を確認。シートは1536×1024、横長背景と配置テストは約1672×941（分かれ道は1671×941）。本番の16:9動画素材ではなく、最終解像度・安全領域の調整は後工程。

## 絵コンテで守ること／まだ作らなくてよいもの

1. 候補の世界観・住民と、現行C06のリンゴロンを確認し、使用した参照を各コマへ記す。通常種10体の方向確認と、C06の演技・構図の承認は区別する。絵コンテはラフ40コマ前後、カットは現行9カットを土台に必要なところだけ変更。
2. 2026-10-18のユーザー訂正で更新：後付けするのはセリフ・字幕のみ。看板・紙・ノートの文字や数字は生成素材に含め、同じ位置から消える演出を検品する。旧参照の無地板は形状参考であり、文字を全部後合成する指示としては使わない。C01は「あおもり」が読めるまま、消失はC02以降。
3. C07は同じ港町・道・船のある3D風景で、光のつながりが消える→航路の結界で船が止まる順序にする。土地と道路は壊さない。架空の沿岸風景であり、実在の日本地図・航路ではない。旧地図の地理資料は履歴として保存し、現行絵の地理精度を証明する出典にはしない。
4. C08は同じ旅のノートの、文字・絵あり→薄れる→ほぼ消える→白紙、の4コマ。文字は紙面内で消し、紙片や筆跡を外へ飛ばさない。C09はC08最終画と[草原の背景候補](../../assets/cinematics/background-concepts/evaluation-batch-01/13-dialogue-awakening-meadow.png)を参照した[接続確認ページ](V00_C09_TRANSITION_REVISION.json)へ変更。ノート→フェード→暗転→次の草原を日本語で示す。草原はV01冒頭の地面すれすれの参考で、V00へ追加再生しない。本番の黒とフェードは編集で作り、黒フレーム専用の画像生成は不要。確認ページ生成と本番生成ジョブを混同しない。
5. V02にC06と同じ種を使えば喪失と回復を対にできるが、現行ゲームの初戦は抽選で種が固定されていない。**V02の採用種・発火条件・導線変更は別判断**。リンゴロンや旧ブナッコへ自動固定せず、今回はゲームの敵や進行を変更していない。
6. 絵コンテの構図が決まるまでは、全住民の詳細リグ・全方向動画・全背景の3Dモデルを作らない。音声・厳密な口の動きも後工程のまま。
