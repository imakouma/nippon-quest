# 追加20体：元ドットと4方向設定画（第6バッチ）

今回の新規20体で、累計100体分になりました。全国分は制作中です。

福島9体・東北地方ボス1体・北海道10体。内蔵画像生成で、元ドット基準の丸くマットな3Dミニチュア調へ展開。ゲーム本体は未変更です。

左上＝正面／右上＝斜め／左下＝右向き側面／右下＝背面。各1536×1024。側背面は補完を含む外観資料で、実3Dモデルや精密な正投影ではありません。

修正版v2：コボシ／ヤオキコボシ（風を誤変換した飾りの除去と裾）、クラドンブリ（麺と背負う器）、ツルガジョウノヌシ（正面の目と配色）、ジャガドドン（背面の不要なひび）。その他15体はv1。今回分はユーザー確認待ちです。

ロクフユノオウは初期の氷形態。覚醒版・各ボスのフェーズ差分は別工程です。
