# 動画台本の共通規則

状態：V00を含む全35本の台本初稿。V00は[40コマ・9ページの絵コンテ画像初稿](V00_STORYBOARD_REVIEW.md)を2026-10-18に制作・内部確認済みで、ユーザー確認待ち。他34本の新規セットの絵コンテ、仮動画、本番動画は未制作。ゲームへの実装完了を意味しない。
本数とIDはVIDEO_MASTER_34.mdを正とする。尺は仮の編集設計で、読み合わせでカット配分を調整する。本数を増やさず必要なら同じ動画内を編集する。

## カット・コマ・素材の区別

- V00は仮尺48秒・現行9カットを土台に、絵コンテ40コマ前後。動作・表情・視線の変化を同じカット内の複数コマで示す。必要な箇所だけカットを変更し、コマ数を理由に増やさない。
- 動画ID（V00）、カットID（C01）、コマID（B01）を分け、例としてV00-C01-B01と記録する。コマが増えても映像の切れ目は自動で増えない。全身の欠落と意図的なクロップを区別する。
- コマには動作の前後、表情・視線、配置、カメラ、字幕・台詞、カット内の順序と仮タイミング、連続性の注意を記録する。複数の事象は時間順に明記し、同時動作として詰め込まない。
- 絵コンテはラフ→字幕付き仮動画で確認。本番静止画は採用構図の開始画・必要な中間／終了画のみ。1コマ＝1完成画＝1生成にしない。他34本のコマ数は演技の複雑さに応じて決める。
- `VIDEO_MANIFEST_34.json`の`shots`は現行の台本上のカット区間。絵コンテのコマや動画生成ジョブ数ではない。絵コンテの追加だけではマニフェストの区間・尺・35本の範囲を変更しない。

## 画面・物語の共通規則

- 16:9、人物だけでなく背景も高解像度。通常ゲームはピクセルのまま。
- ミチルは手のひらサイズ・最新4枚翼・柔らかい女性声。主人公にだけ見える。シオリやカナエが直接ミチルを見たり返事する画を作らない。
- 主人公の一人称やプレイヤー名を固定音声へ入れない。字幕の話者名はゲーム側。
- 相棒未選択の序盤へ御三家を出さない。選択後の共通動画は相棒の全身を固定せず、画面外の反応・手元・主観で3差分を増やさない。必要な反応はゲーム側Hで補う。
- 加入3本は選択した一体だけ。玉内像は紹介であり実体が三体同時に目覚める意味ではない。
- 進化後も同じ相棒だと演技で示す。名称・ID・条件・能力は今回の台本で勝手に確定しない。
- 本番映像の文字や地図の署名はAI生成画像に任せず、編集で重ねる。本番原画・16:9映像枠の中に台詞を焼き込まない。確認用の絵コンテでは、白い余白に話者・短い台詞・語り・無言の芝居を添えた別ファイルを作ってよい。元絵を保持し、注釈版を本番動画の入力にしない。
- V00の台詞原本と40コマ対応は[V00_DIALOGUE_BOARD_REVISION_V1.json](V00_DIALOGUE_BOARD_REVISION_V1.json)。一つの発話を複数コマで分けて表示しても、各コマで繰り返し発話しない。全コマへの台詞追加は強制せず、反応と無言の間を残す。開始・終了時刻は仮配置で、声の実測尺は未検証。
- 台詞は新規脚色を含む。物語正本の事実を優先。背景説明文はスタッフ向け、台詞はRubyText。
- ミチルの秘密は開示しない。V25は任意の警告、V33は不自然な一言まで。
- 地方ボス浄化は死亡ではない。高解像度の浄化後造形は各ボスの制作時に決める。
- 対峙→プレイヤー戦闘→勝利後映像の境界を守る。動画で戦闘結果や問題の答えを確定しない。
- 完走・スキップ・読込失敗でも報酬、加入、進化、地方クリアの整合を保つ。視聴履歴とゲーム進行フラグは区別する。
- クロップでの頭・胸上表示は可。ただし全身表示で尾・手・翼が欠落しないよう検査する。
- 表のカット秒数は合計尺の設計値。現在は配役・音声生成を後回しにし、台詞の読み合わせと字幕で仮の発話時間・反応の間を確認する。音声承認を動画生成の条件にしない。
- 編集元、台詞・字幕タイムライン、音声なし映像を保持する。会話には調整可能な前後の保持時間を設け、仮の口の動きを音声同期済みとは扱わない。後日の声の実測で尺・字幕・厳密な口の動きを調整し、必要なら会話ショットを再編集・再生成する。
