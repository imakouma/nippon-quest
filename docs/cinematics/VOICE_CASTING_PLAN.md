# キャラクター音声・キャスティング計画

更新日：2026-10-17。キャラ別の固定声という方針は維持／個別の声は未承認。ユーザー指示により、配役・音声生成は後回し。映像制作の着手条件にしない。

## 目的と制作順

全35本の専用動画と高解像度会話で、同じキャラクターが別人の声にならないようにする。今は台詞・字幕と仮尺で絵コンテ・仮動画・映像を進める。音声制作をユーザーが再開するときは、ミチル4候補→ユーザー試聴・選定→感情別の再現性確認→主要人物→御三家・魔王→地方ボス・住民の順。配役表の声質は提案であり、採用音声ではない。

声を映像から独立して制作する。現在は台詞と仮尺→絵コンテ→字幕付き仮動画→本番静止画・映像。後日、音声の承認→実測尺で保持時間・字幕・会話ショットを調整→厳密な口の動き→BGM・環境音・効果音との合成を行う。動画生成時に付いた声で承認音声を置き換えない。口の動き・音声なし版・字幕タイムライン・編集元を分けて保存し、声が決まるまで会話尺を最終固定しない。後付けで完全に合う保証はなく、再編集・一部再生成が必要になる可能性を残す。

## ミチル：音声制作再開時の4候補

全候補共通：標準的な日本語、自然で柔らかい女性声。男性的な低い響き、甲高い幼児声、過剰なアニメ演技、過度な息声、機械的な読み上げは避ける。小柄さを極端な高音だけで表さない。実在の声優・人物の模倣や無断クローンはしない。

|候補|声質・演技の違い|
|---|---|
|A 自然な相棒（基準候補）|中高音、澄んだ柔らかさ。近い距離で普通に話す。明るいが落ち着きもある|
|B あたたかい案内役|Aより少し低めで丸い響き。ゆっくりすぎず、安心させる自然な語り|
|C 軽やかな好奇心|Aより少し明るく軽い響き。歯切れよく、元気だが騒がしくしない|
|D 静かな透明感|中高音のすっきりした響き。控えめな抑揚でも感情が伝わる。冷淡・無表情にはしない|

比較用テキストは全候補で同一とし、BGM・残響・効果音なし。以下は試聴専用で、ゲームの台本を置換しない。TTS入力時はRuby注記を取り除き、必要な読みを別途指定する。

1. 通常・自己紹介：「よかった、気[き]がついたんだね。ミチルだよ。いっしょに行[い]こう。」
2. 喜び→不安→決意：「やったね！ ……でも、この先[さき]は少[すこ]し心配[しんぱい]。大丈夫[だいじょうぶ]、ひとりにはしないよ。」

初回は各候補で2台詞をまとめた短い比較音声を1本ずつ、計4本。声の本人性、女性らしい自然さ、聞き取りやすさ、既存キャラ像への適合で選ぶ。採用後に通常・喜び・不安・怒り・決意を別々に生成しても同じ声に聞こえるか確認する。試聴順と候補ラベルを明示し、比較時の音量差を抑える。

## 主要キャラの配役案

|対象|声の方向性案|連続性・区別|
|---|---|---|
|ミチル|上記4候補から選ぶ自然な女性声|全編共通。秘密を匂わせる場面でも突然別人にしない|
|主人公|中性的で素直な子どもの声|短い返答・息・驚きを中心に試す。名前・一人称を固定しない。採用前に見た目との相性確認|
|シオリ|快活で親しみやすい同年代の声|主人公より歯切れよく、ミチルより地に足のついた響き|
|カナエ|穏やかで芯のある若い女性声|ミチルと区別できる落ち着き。回想と現在の関係を管理|
|カグラビ（3形態）|元気な獅子犬の鳴き声|言葉を話す配役にはせず、同系統の鳴き声を成長させる案|
|イズミコ（3形態）|水のように澄んだ、かわいくクールな鳴き声|形態ごとに響きと長さを成長させ、エイの個体性を維持|
|コダマル（3形態）|柔らかく知的なフクロウの鳴き声|成長につれ深み・落ち着きを増す。水属性と音色を分ける|

|社の守り人|穏やかで年長者らしい声|序盤の説明が聞きやすい。専用キャストの要否を試聴で判断|

|地方ボス9体|造形・章の主張に合わせ個別に設計|上記8主要キャラの承認後に追加。魔王の声と混同させない|

## 固定・保存する情報と検品

- キャラID、採用候補、承認日、担当声優または音声サービス・音声ID、モデル名・バージョン（公開される場合）。
- 参照音声と利用権、声質指示、速度・安定性・類似度等の実際に対応する設定。シードがあっても同一声の保証としない。
- 通常・感情別の承認基準音声、アクセント・固有名詞の読み辞書、各セリフIDと動画・カットID。
- 生成リクエストID、入力全文、生成日、原音、採用テイク、編集履歴。モデル更新時は既存音声を保存し、基準との回帰試聴後に新録へ使う。
- 原音は可能ならWAV。音量・歯擦音・ノイズを共通基準で処理し、囁き・叫びの演技差は残す。残響や覚醒効果は原音へ焼き込まず別管理。
- 同じセリフだけでなく、長文、疑問、感情変化、固有名詞でも声が崩れないか確認。日本語の読み間違い・不自然な間も検品。
- 採用ファイルをゲームへ固定配信。ブラウザ標準読み上げは端末で声が変わるため、この映像用キャストの代用にしない。
- 商用ゲーム利用、保存・加工・配信、クローン同意、データ保持条件を採用サービスの最新規約で確認。新しいプロバイダー経路・認証情報の追加は別途確認する。

## 現状と再開条件

2026-10-17：モデル推薦の読取時点でfal接続が再認証を要求した。音声ジョブは未送信、4候補の音声は未生成。その後ユーザーが音声を後回しとしたため、現行工程では再認証・モデル探索・試聴制作を行わず、V00の絵コンテへ進む。認証エラーは映像工程のブロッカーではない。

ユーザーが音声制作を再開した後に、接続の再認証が必要か確認する。アカウント状態→日本語対応・再利用可能な声のモデルとスキーマ→料金・利用条件を確認して4本だけ試作する。候補を選んだだけでモデルの再現性が保証されたとはしない。

OmniRouteは今回は採用しない方針：音声品質・声の保持機能を直接確認する試聴段階では既存の音声接続を使い、追加の中継による品質・遅延・障害点・データ共有先・規約・費用の不確実性を増やさない。中継を導入する場合はこれらを比較してユーザー承認を得る。Codex自体の経路や既存プロンプトの送信先は変更しない。
