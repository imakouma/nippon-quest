# 高解像度キャラクター・ビジュアル基準

Status: 味方7体と御三家3段階の方向確認済み / 魔王デザイン選定中
Scope: 高解像度イベント映像、キャラクター紹介、将来の3D表現
Gameplay: フィールドと通常バトルは従来どおりピクセル表現を維持する

## 目的

- 高解像度イベントで使う8体の正式な見た目を、動画制作より先に確定する。
- 小さい表示でも誰か分かる太いシルエットと、アップにも耐える表情を両立する。
- ピクセルRPGと映像の印象を断絶させず、同じ配色・形・象徴物を共有する。

## 通常マナビモノ10体の追加参照（2026-10-18）

主要8体とは別に、実際の出現データにいるリンゴロン、ネブタン、ドグウくん、ウミニャン、トオノカッパ、ワンコソバット、ズンダマル、アキタイヌ、ショウギコマンダー、アカベコンを制作した。元ドットの形・配色・象徴物を引き継ぎ、マットな3D調へ統一。ユーザーは基本デザインと、その後の4方向シートの方向を確認済み。

- 基本案：[画像パス・入力・プロンプト](TOHOKU_MONSTER_CONCEPTS_V1.json)。リンゴロンだけは[顔v2](../../assets/cinematics/monsters/tohoku-roster-v1/aomori-ringoron/concept-v2-face.png)を優先し、旧v1の大きな黒い目・開いた口へ戻さない。
- 各1枚・計10枚の正面／斜め／側面／背面：[4方向資料](TOHOKU_MONSTER_TURNAROUNDS_V1.json)。側背面は造形の補完を含む視覚資料で、リグ付き実3Dモデルや厳密な正投影設計図ではない。
- 方向確認はラフ絵コンテの参照として扱い、本番映像用の可動・表情・サイズの最終ロックとは分ける。V00のC06はリンゴロンを使う演技案へ更新したが、ゲームの初戦や種の役目は変更しない。

## 参考作品から抽出する造形言語

参考作品は STING の『VIractal』。衣装、キャラクター、ロゴ、画面配置を直接コピーせず、次の抽象的な特徴だけを参考にする。

- 2.5〜3.2頭身を基準にした、手作りミニチュア人形のような存在感。
- 髪、耳、翼、武器など、遠目でも読める大きな形を1つ持たせる。
- 胴体と手足は短くまとめ、手、靴、小道具をやや大きくする。
- 質感はつやを抑えた塗装済みフィギュア調。発光や粒子を品質の代わりにしない。
- 基本配色は「主色1色＋副色1色＋布や革の中性色」。金色は小さな焦点だけに使う。
- UIは暗い半透明パネル、カード、六角形、太い枠を候補とし、情報をモジュール単位で整理する。

## 採用しない方向

- 全身を覆う星、常時のラメ、過剰な金装飾、強いブルーム。
- 7〜8頭身の一般的なソーシャルゲーム風美少女・美少年表現。
- 髪や衣装の細線だけで個性を作り、小さい表示で輪郭が潰れる設計。
- 参考作品の固有キャラクター、衣装、UI、ロゴを見分けがつく形で模倣すること。

## モデルシート共通仕様

- 1枚にヒーローポーズ、正面、側面、背面、表情5種を配置する。
- 背景は明るい無彩色。影は接地を示す弱い影だけにする。
- 正面・側面・背面は同一身長、同一衣装、同一比率で揃える。
- 表情は通常、喜び、心配、怒り・決意、驚き。役割に合わせて一部変更可。
- 文字やロゴは画像生成に含めず、採用後に別レイヤーで管理する。
- 動画用の正式シートには、配色見本、素材、発光箇所、可動時の注意点を追記する。

## キャラクター別アンカー

### ミチル

- 2026-10-15に簡略3D案05を正式な造形基準として採用した。
- 手のひらサイズの道案内の妖精。約2.7頭身の丸いゲームモデル体形。
- 深い藍紫、生成り、くすんだ空色。金色は胸元の羅針盤と鞄の留め具だけ。
- 大きな二色マフラー、花びら形の一枚服、折り返しのある短いブーツを主要な輪郭にする。
- 翼は模様のない幅広の4枚。上2枚を大きく、下2枚を小さくする。
- 髪、服、翼は細線ではなく大きな立体の塊で作り、縫い目や装飾模様を足さない。
- 頭上の飾り、常時の星粒子、過剰な発光は使わない。必要な場面だけ胸元の羅針盤を弱く光らせる。
- 正式参照画像は `assets/cinematics/characters/michiru/model-sheet-v3-approved.png` とする。

### 主人公

- 2026-10-15時点では、共通素体候補の一番左を主人公の正式な高解像度基準として採用する。
- 性別を限定しない人間の子ども。温かい褐色寄りの肌、焦げ茶色の目、短い黒髪、上向きに曲がる一房を固定する。
- 青緑の短い上着、大きな生成りの丸襟と袖口、無地のインナー、膝丈の短パン、地図袋、折り返しのある短いブーツで構成する。
- 胸元はミチルの羅針盤と区別し、青い玉を中央に置いた単純な「むすびの輪」とする。針、星、方位記号は入れない。
- 正式参照画像は `assets/cinematics/characters/protagonist/model-sheet-v1-approved.png` とする。
- 将来カスタマイズを復活させる場合は、このモデルを共通素体として髪・肌・服の差分を載せる。

### シオリ

- 同年代の記録係。旅の手帳と短い鉛筆を大きな小道具にする。
- 好奇心が先に立つ前傾姿勢。紙、布、革の手触りを中心にする。
- 初回案は主人公と髪型、上着、短パン、ブーツの輪郭が近すぎたため不採用とする。`model-sheet-v1-rejected-too-similar.png` として比較用に残す。
- 主人公の「短髪・短い上着・短パン・折り返しブーツ」と重ならない輪郭を必須とする。
- 再設計候補は `redesign-01-side-ponytail.png`、`redesign-02-beret-overalls.png`、`redesign-03-twin-buns-tunic.png` の3案とする。
- 手帳を唯一の大きな小道具にし、細かな文具や装飾を追加しない。
- 2026-10-15に再設計候補02「赤い丸帽子＋緑のオーバーオール」を正式採用した。
- 栗色の短い髪、大きな煉瓦色の丸帽子、生成りのシャツ、苔緑の幅広オーバーオール、煉瓦色の低い靴を固定する。
- 主人公との差を保つため、短い上着、短パン、折り返しブーツ、胸元の印、肩掛け鞄は使わない。
- 正式参照画像は `assets/cinematics/characters/shiori/model-sheet-v2-approved.png` とする。

### カナエ

- 主人公の姉。安心感のある直立姿勢と、観察者としての静かな鋭さを両立する。

- 子ども組より約1頭身高くし、長い縦方向の輪郭と落ち着いた直立姿勢を使う。
- 正体の伏線は方位記号ではなく、袖口または帯端にある小さな無地の輪形へ弱める。

- 第3形態は装飾量だけでなく、生息域、能力、守る対象を拡張する。
- 第1形態は親密さ、第2形態は自立と行動性、第3形態は威厳と完成した役割を表情と姿勢で示す。

### 知識喰いの魔王

- 日本編で目に見える最終敵。紙片、本の背、空白になった文字を大きな形へまとめる。
- 子ども向けの読みやすさを保ちつつ、8体の中で唯一、上から覆いかぶさる逆三角形の輪郭を使う。
- 初回比較画像：`assets/cinematics/characters/knowledge-devourer/concept-options-v1.png`。左から静かな書庫の王、巨体の書物獣、紙冠の君主。採用未決定。
- ユーザーが中央の「巨体の書物獣」を通常形態の基準として選定した。上記の採用未決定は履歴。
- 覚醒形態の方向確認画像：`assets/cinematics/characters/knowledge-devourer/normal-awakened-v1.png`（左が通常、右が覚醒候補）。
- 覚醒は書物による封印がほどけ、墨の本体と奪った知識の核が露出する構想。頭部の本が三方向の紙翼へ開き、墨の頭が立ち上がる。胸の欠けた金輪が二つの弧に分かれて白い核を囲み、下半身は一本の墨尾から三本の流れへ変化する。
- 演出候補：ページが静止→金輪が開く→周囲の文字が消える→紙翼と核が現れる。覚醒時の台詞案「すべてを、白紙に戻そう。」。
- 覚醒の採用、発動条件、戦闘仕様、正式名称は未確定。現時点ではビジュアルと演出の構想のみで、ゲームの挙動は変更しない。

## UIへの展開方針

- キャラクター選択は、中央に大きなミニチュアモデル、周囲に役割・特徴・相性をカードで配置する。
- 通常時は暗い半透明の面と明るい太枠を使い、選択中だけキャラクターの主色を強く出す。
- 小学生向けに、文字より顔、色、属性アイコンを先に読める構造にする。
- 参考作品の密度をそのまま持ち込まず、学習情報が出る画面では選択肢と主要数値を大きく保つ。
