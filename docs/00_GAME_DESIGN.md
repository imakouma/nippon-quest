## 1. コンセプト

- **ゲームが主体、勉強が要素。** 「勉強アプリにゲームの皮をかぶせたもの」ではなく、「ちゃんとしたドット絵RPGを遊んでいたら、結果的に学力がついていた」を目指す。
- 判断基準（迷ったらこれに戻る）：
  1. 問題を解くことが「ゲーム内の行動そのもの」になっているか？（例：算数の計算が攻撃力を決める／漢字を読むと宝箱の封印が解ける）。「戦闘の合間に急にクイズ画面が出る」は最終手段。
  2. 不正解でもゲームが止まらないか？ 不正解＝「弱い攻撃」「宝箱の中身がランク落ち」であって、「進めない」ではない。**プレイヤーは負けても学べるし、学ばなくても遊べる。ただし学ぶと圧倒的に有利。**
  3. 小学生が説明書なしで直感的に触れるか？ 文字を読ませる前に、絵と動きで伝える。
- ターゲット：小学1〜6年生（日本編）。中学生向けの世界編は将来のフェーズ。設計上は「ワールド（日本／世界）」を差し替えられる構造にしておく（§9）。

### 2.2 島の中の構造

- 島（地方）の中は **県ごとのフィールド**（Tiled 形式の JSON マップ）に分かれる。**県はそれぞれ海にかこまれた島** として描く（県の外の陸地も海にする。となりの県へ歩いては行かない）。
- 歩ける「地方マップ」は作らない。地方の全体は、フィールドの右上の **「にほんちず」** で見る。地方ごとの地図の上で、県ごとに **見つけた名所の数・中ボスを倒したか・いまいる場所** が分かり、**行ったことのある県（ロック解除）だけ** えらんで そのフィールドへ行ける（まだの県は灰色。中ボスを倒して ワープホールから行く）（地図のデータは `pnpm scaffold:maps` が `public/worldmap.json` に作る）。
- 都道府県ごとの **エリア** は、以下で構成される：
  - **フィールド**：その県の名所・特産品をモチーフにした地形（例：青森 → りんご園、津軽海峡の浜、十和田湖、恐山の霊場、三内丸山の遺跡）。
  - **地面の 性質**：フィールドの マスには 地面の 種類が ある（`src/core/world/ground.ts`）。`pnpm scaffold:maps` が 実在の 地形から 決めて タイルで 描き分ける：**くさはら**（ふつうの 平地。花や 草の もよう）・**もり**（丘の ふちと そのとなり。まるい 木と とがった 木）・**やま**（丘の おく・高い山。岩山と ごろごろ岩）・**すなはま**（海の となり）・**みずべ**（湖・沼の そば。宮城は 伊豆沼の まわり。水たまりと ガマ）・**たんぼ・はたけ**（海からも 丘からも はなれた 平地。みどりと こがね色の たんぼ。青森・山形・長野は りんご・さくらんぼ、福島・山梨・岡山は ももの 果樹園も）。立っている 地面で **出る モンスターが かわる**（`content/prefectures/<県>.json` の `encounters` の `zone` に 地面の 名前 `forest` / `mountain` / `beach` / `shore` / `farm`。表の 無い 地面と くさはらは `field` の 表）。すなはまなら 海の モンスター、もりなら 森の モンスター（例：青森の すなはま＝ウミニャン・マグロード、もり＝ブナッコ。東北の 表は `05_TOHOKU_SEED.md` §6.2）。**バトルの 背景も 地面ごと**（木の 列・雪の 岩山・海と 島・湖と あし・たんぼと かかし）。いまの 地面の 名前は 画面に 出さない（見た目で わかるように 描き分ける）。町・ダンジョンは 地面を 使わず、島マップは 絵だけ 地面で 描き分ける（島では エンカウントしない）。
  - **フィールドの 見た目（ドラクエ風）**：情報を しぼって すっきり 見せる。カメラは 3 倍（1 マス 48px。画面に 横 27×縦 15 マスくらい）。地面の データ（background）の 上に 見た目だけの レイヤーを しく（`src/scenes/overworld/overworldView.ts` が どの 絵かを 決め、`viewTiles.ts` が 描く。町・ダンジョンは そのまま）：海は 陸との さかいに 白い 波と あさせ、森は ひとかたまりの こずえ（ふちは まるい）、山は 1 マス 1 つで ならぶと 山なみ、すなはまは 草の がわを まるく、田んぼは 草原と 同じ 色に なえの 列、果樹園は 1 本ずつ 実の なる 木。たはた・果樹園の まとまりは まるい 形（四角い まとまりは つぎはぎに 見えるので、`scaffold-maps.ts` の `groundTiles` が なめらかな noise で 分ける）。町・ダンジョン・裏ステージ・島への 船の 入口は、家・どうくつ・お城・船の しるし（`entranceIcons.ts`）。左上の 窓（県の名前・★・小さな地図）は **歩いている あいだは かくし、止まって 0.7 秒で 出す**。
  - **町（1つ）**：ショップ・宿屋・かじや・ミッション掲示板・図鑑係のNPC。広場・屋台・花だん・畑・井戸・街灯のある町で、お店は かべの看板（アイコン）で見分けられる。**見た目は県ごとに その土地の特ちょうで変える**（`scripts/data/towns.ts`）：地面（草・雪・砂）、木（まるい木・松・雪の松・ヤシ・さくら・竹）、屋根（色・かわら・沖縄の赤がわら・雪・かやぶき）、広場のまん中の名所（お城・首里城・五重塔・神社と鳥居・温泉・灯台・東京タワー・時計台・まつりの山車・恐竜・ふんすい）、南の畑の特産品（りんご・みかん・もも・なし・ぶどう・田んぼ・茶畑・ラベンダー・チューリップ・キャベツ・パイナップル・ネモフィラ・いちご・小麦・スイカ）、街灯（石どうろう・ちょうちん）、海ぞいの町は北が海（船・桟橋・すなはま。広島は海の鳥居）、小物（雪だるま・シカ・湯けむり・シーサー）。例：北海道＝雪と時計台とラベンダー、沖縄＝赤がわらとヤシと首里城とシーサー、京都＝かわらと竹と五重塔と茶畑。お店は content に書いていなくても、おみせ・やどや・かじや・けいじばん が どの町にもある。町の人（content にせりふが無い人）は、その県の名所・特産品を 1 つ教えてくれる。
  - **ダンジョン（1つ）**：いくつもの部屋を通路でつないだ迷路（シード付き乱数で生成）。県ごとに 洞くつ・氷の洞くつ・地底湖・神社 の見た目があり、たいまつ・岩・水たまりなどの小物がある。いちばん奥の部屋に祭壇と宝箱。奥に **県ボス** がいる（倒すと「県のしるし」）。県ボスは 宝箱の手前に立って祭壇を守る（場所はマップの `boss_<県>`、だれかは `content/prefectures/<県>.json` の `boss`）。見た目は中ボスと同じ「？」マークで、ぶつかると「？？？」として ボス本人のセリフ（`fieldLine`。例：ナマハゲオウ「なまけものは いねがー！ きょうの べんきょうは、ちゃんと したか？」）→「たたかう？」→ にげられない戦い。倒すと `progress.areaSigns` に 県のしるし が入り、「？」は消える。
  - **裏ステージ（県ボスのあと）**：県ボスを倒すと、フィールドの その土地の名所（`scripts/data/secrets.ts`）にある 暗い入口が ひらく（それまでは のると「おもい とびらが しまっている…」）。中は お城・やかたの中（木の床・たたみ・しょうじ）の 迷路（マップ `<県>-secret`）で、いちばん奥に その土地の **歴史上の人物** が ラスボスとして 立つ（「？」マーク。名前を名のって しょうぶを いどむ → にげられない戦い。倒すと `progress.eventsDone` に `lastboss.<県>`）。だれかは `content/prefectures/<県>.json` の `secret`。東北：青森＝津軽為信（弘前城）、岩手＝源義経（平泉・高館）、宮城＝伊達政宗（仙台城 本丸）、秋田＝佐竹義宣（久保田城）、山形＝松尾芭蕉（山寺）、福島＝蒲生氏郷（鶴ヶ城）（`05_TOHOKU_SEED.md` §7）。
  - **中ボス（フィールドに1体）**：町からダンジョンへの道の途中に、**「？」マーク**（1 マス。だれがいるかは戦うまでわからない。地図でも「？」。小物に見えないよう、まわりに光のわっか・足もとの光る輪・立ちのぼる光のつぶの **オーラ**）で **決まった場所に立ちふさがる**（歩き回らない）。ボスの姿はバトルで はじめて見える（バトルでは ふつうのモンスターより一回り大きく出す）。ぶつかると「たたかう？」→ にげられない戦い。倒すと、そのマスに **次の県へのワープホール** が開く。次の県は `content/world/japan.json` の `areas` の並び。島の最後の県からは、次の島（`order` の次）の最初の県へ。だれが中ボスかは `content/prefectures/<県>.json` の `midBoss`。
  - **名所の ★ 看板と 特産品の宝箱（あわせて 1 県 8〜12 か所。北海道は 18、離島マップにも 2〜3 か所）**：実在の場所に ★ の看板が立ち、**近づくだけで** カットインと ひとこと解説、またはミニイベントが始まる（§7）。**特産品（食べもの・工芸品）は その産地に 宝箱として置く**。しらべて あけると カットイン「とくさんひん はっけん！」→ 特産品の説明 → その特産品のアイテム（`content/items/<県>-<motif の id>.json`。食べものは HP かいふく、工芸品は素材）が もらえる。あけた特産品も 図鑑（`dex.motifs`）と にほんちずの数に入る。特産品のアイテムは、その県のモンスターを たおしたときの **ドロップ** でも 手に入る（その県の特産品の どれかを 合わせて `settings.specialtyDropRate`＝35% で。`src/core/progression/specialty.ts`）。ドロップしたときは バトルの おわりに 名前の帯 →「とくさんひん『〇〇』を てに いれた！」→ 特産品の説明（motif の blurb）が出る。**アイテムには ぜんぶ アイコンがある**（本番の絵が できるまでは `src/scenes/art/itemIcons.ts` が 名前に合った 16×16 のドット絵を つくる。宝箱・特産品のカットイン、バトルの どうぐの窓・てに いれた もの に出る）。場所（名所・自然・歴史・祭り）と特産品を半分ずつくらい、県の あちこちに ちらばらせる。**★ の色で進みぐあいがわかる**：灰色＝まだ見つけていない、白＋上に「！」＝見つけたが チャレンジ（問題）がまだ、金色＝チャレンジまで終わった。フィールドでは看板・中ボス・入口などの上に名前の札（ポップアップ）は出さない。
- **地方ボスの城** は、全県の県ボスを倒す（＝「県のしるし」を全部集める）と入れる。地方マップをなくしたので、城の入口をどこに置くかは未定（島の最後の県のフィールドに置く／にほんちずから入る、など）。城ができるまでは、島の最後の県の中ボスのワープホールで そのまま次の島へ行ける。
- 都道府県の内容（名所・特産品・モンスター・ボス・アイテム）はすべて `content/prefectures/<code>.json` に外出しする（→ `04_CONTENT_TEMPLATES.md`）。

### 2.3 主人公

- 名前入力可（ひらがな・カタカナ・英字、最大6文字）。デフォルト名「ハル」。
- 性別選択なし。見た目（髪色・肌色・服色）を3×3×3から選ぶ。ドット絵なのでパレットスワップで実装。
- 見た目のドット絵：フィールドでは **全身の歩行ドット絵**（16×24、4方向×3コマ）、バトルでは横向きのポーズ（`docs/06_ART_BIBLE.md` §2）。
- 相棒モンスター（スターター）：最初に3体から1体を選ぶ（火・水・草 相当の3すくみ。名称はゲーム内では「ほのお／みず／くさ」ではなく日本モチーフに寄せる：**ヒノ／ミズ／モリ**）。

## 3. コアループ

```
探索（フィールド・町・ダンジョン）
 ├─ モンスターに遭遇 → バトル（§4）→ 経験値・ドロップ・仲間化
 ├─ 名所でイベント発生 → ミニゲーム型の問題（§5） → アイテム・装備・図鑑（名所スタンプ）
 ├─ 中ボスを倒す → ワープホール → 次の県へ
 ├─ 町：ショップ／合成／ミッション受注・報告
 └─ ダンジョン最奥 → 県ボス → 「県のしるし」
全県のしるし → 地方ボス → 次の島へ
```

1プレイセッションの想定：**10〜15分**（小学生の集中時間と、保護者が区切りやすい長さ）。セッション単位で「今日のごほうび」（デイリーミッション）を1つ用意。

## 4. バトルシステム

### 4.1 形式

- **ターン制バトル**（主人公＋前に 立つ 仲間モンスター＝オトモ vs 敵 1 体）。ドラクエ／ポケモンの中間くらいの複雑さ。**秒数では なく ターンで すすむ**（純粋ロジックは `src/core/battle/engine.ts` の `act`。1 回 よぶと 1 ターンぶんが 決まる）。
  - **1 ターンに 主人公 → オトモ → てき が 1 回ずつ 動く**（じゅんばんは いつも こちらが 先。すばやさでは 入れかわらない）。だれでも 1 ターンに 1 回だけ で、ボスの フェーズでも 行動は ふえない（`bossPhases` の `actionsPerTurn`、モンスターの `actionIntervalMs` は つかわない）。
  - 主人公が コマンドを えらぶと その ターンが すすむ。**コマンドが 成立しなかった とき**（教科ゲージが たりない・ボスから にげられない など）は ターンが すすまず、えらび直せる。主人公が たおれて いる ターンは えらべないので、オトモ → てき だけ すすむ。
  - オトモ（出撃中の 仲間）は 主人公の あとに 1 回 自動で こうげきする（問題なし＝倍率 1。使う わざは ゲージを 使わない こうげきわざの いちばん 強いもの）。**パッシブ**：その わざの 教科の ゲージが 1.5 倍 たまる（`subjectGauge.companionBoost`）。敵は 前に 立つ オトモを ねらい、たおれると 生きている 次の 仲間が 自動で 前に 出る。仲間が みんな たおれると 主人公が ねらわれ、主人公が たおれたら まけ。
  - 問題を といて いる あいだは 時間が うごかない（そのターンの 主人公の 行動を 決めて いる だけ）。答えが 出てから、主人公 → オトモ → てき の 演出が じゅんばんに ながれる。
- コマンド：**たたかう／必殺技（ひっさつわざ）／どうぐ／いれかえ／にげる**（敵の HP が減ると **さそう** が出る）。バトルの画面では「わざ」を **必殺技** とよぶ（コマンドもメッセージも「必殺技[ひっさつわざ]」とふりがな付き。わざを おぼえたときの文も同じ）。どうぐは HP の 割合が いちばん 低い 味方に 使う。
- 見た目は **サイドビュー**（敵が左、主人公と相棒が右。SFC 時代の RPG の横からの画面）。上に「てき」「なかま」の窓（名前・HP ゲージ・MP）、下にメッセージ窓（「＊」で 1 文字ずつ。「〇〇が あらわれた！」など）、コマンドは下の左に 3 列の黒い窓で ♥ カーソル。主人公の「たたかう」は 5 しゅるいを じゅんばんに（横切り → ジャンプ切り → 二連切り（×）→ つき → 回転切り）。仲間は ぴょんと はねて体当たり（仲間の属性の色）。敵は白く 2 回光ってから、とびかかって ひっかく → つっこんで 体当たり → とびかかって かみつく を じゅんばんに（ボスは 2 回に 1 回 とびあがって ドシン＝地ひびき、画面がゆれる）。当たると 星・光の わ・属性の かけら（火の粉・あわ・葉・小石・風・きらめき・やみの ほのお）が ちり、会心は 大きな ×印。味方が うけると ひっかき・かみつき・体当たり・地ひびき の しるし。必殺技は ため（属性の かけらが あつまる）のあと 属性ごとに ちがう動き（ヒノ＝火の玉、ミズ＝水の波、モリ＝葉っぱのうず、ツチ＝岩が落ちる、カゼ＝風の刃、ヒカリ＝光の柱、ヤミ＝やみの玉）で、★ が多いほど数がふえて はでになる。回復・まもりは 光の わ。動きは `src/scenes/battle/motions.ts`、エフェクトの ドット絵は `battle/fxArt.ts`。**ポケモン風の「足場＋後ろ姿＋HP 枠」のレイアウトやセリフ（「こうかは ばつぐんだ」「いけっ！」など）は使わない。**
- リアルタイムの 画面：コマンド窓の 上の 段に コマンドゲージ、敵の 足もとに こうげきタイマー、右に 教科ゲージの 窓（白い 目もり＝必殺技に 要る 量）、「なかま」の 窓の HP の 下に 時間の ゲージ（主人公＝コマンドゲージ、オトモ＝自動こうげきまで）。2 コンボ いじょうで「〇コンボ」。たたかいの ようすの 文は 待たずに ながれる（決着・ボスの セリフだけ タップ待ち）。
- 通常攻撃「たたかう」は問題なしで撃てる（ゲームが止まらない保証）。かわりに コマンドゲージが たまるのに 時間が かかる（問題に こたえる 必殺技の ほうが 強くて はやい）。
- **教科ゲージ**（こくご・さんすう・りか・しゃかい・せいかつ・えいご。それぞれ 0〜100、バトルごとに 0 から）：必殺技の 問題に こたえると その教科の ゲージが たまる（クリティカル 40／グレート 30／グッド 15／ミス 10。`subjectGauge.charge`）。必殺技には それぞれ 使う ゲージの 量（skills の `costGauge`：★1＝0＝基本わざ、★2＝50、★3＝100）が あり、ゲージを 使う 強い 必殺技は たまって いる ときだけ 打てる（MP は使わない。MP は敵のわざだけ）。教科ごとの **固有スキル**（こくごバースト など。`subjectGauge.uniqueSkills`、ゲージ 100・いりょく 180）は、主人公か オトモの わざに ある 教科なら だれでも 使える（問題は プレイヤーの 学年と ひとつ下から）。
- 必殺技の 一覧には 主人公の わざ・前に 立つ オトモの わざ（こたえると オトモが 使う）・固有スキル が ならぶ。
- **「必殺技」を選ぶと問題が発動する。** 必殺技（データ上は skills ＝わざ）はすべて教科に紐づいており、問題の出来がわざの威力・効果を決める（§4.3）。

### 4.2 ステータス

- HP / MP / こうげき / ぼうぎょ / すばやさ / かしこさ。すばやさは にげる 成功率に 効く（ターン制なので じゅんばんは かわらない）。
- 「かしこさ」は問題の正答で上がる隠しパラメータ的な成長要素。わざの威力係数に効く（必殺技の いりょく ×(1 ＋ かしこさ × 0.01)）。学年が上がっても「勉強したぶん強くなる」実感を出すための軸。
- 属性：**ヒノ（火）／ミズ（水）／モリ（草）／ツチ（土）／カゼ（風）／ヒカリ／ヤミ**。3すくみ＋相殺。各県のモンスターは県のモチーフに合った属性を持つ（青森の「ねぶた」系はヒノ、津軽海峡系はミズ…）。

### 4.3 問題→戦闘への変換ルール（ここが「ゲーム主体」の肝）

問題エンジン（§5）はバトルエンジンに **`QuestionResult { score: 0.0〜1.0, timeMs, attempts }` だけ** を返す。バトル側は **score だけ** をこう使う（エンジンに わたす `ActionResult` の timeMs は シーンが はかった 時間、attempts は 1。ロジックには 使わない）：

| score | 判定（演出） | 効果 | コンボ（連続成功） |
|---|---|---|---|
| 1.0 | 「クリティカル！」 | わざ威力 ×2.0 | +1 |
| 0.5〜0.99 | 「グレート！」 | わざ威力 ×1.2 | +1 |
| 0.01〜0.49 | 「グッド！」 | わざ威力 ×0.8 | 0 に もどる |
| 0 | 「ミス…」 | わざ威力 ×0.5（**0ではない**。行動は必ず成立する） | 0 に もどる |

- ダメージ式（`src/core/battle/damage.ts`）：BaseDamage ＝ こうげき × いりょく（power / 100。必殺技は かしこさ で アップ）÷ ぼうぎょ × `damageScale`（12）、ComboBonus ＝ 1 ＋ コンボ × 0.05（最大 +50%）、FinalDamage ＝ BaseDamage × できばえの 倍率 × ComboBonus × 属性の 倍率（相性表 × じゃくてん × セット装備）× かいしん。最低 1。問題の ない こうげき（たたかう・オトモ・敵）は できばえの 倍率 1。
- **コンボ**（連続成功）で いりょく（上の ComboBonus）・**かいしん率**（5% ＋ 1 コンボ 2%、最大 25%。「かいしんの いちげき！」×1.5）・**けいけんち・おかね**（その バトルで いちばん 長かった コンボで 1 ＋ 0.05 × n 倍、最大 1.5 倍）が 上がる。量は `settings.json` の `combo`。streak はバトルをまたいで保持しない。
- 制限時間は「気持ち急かす程度」（低学年 20秒／高学年 15秒、`settings.json` で調整）。時間切れも score 0 扱い、行動は成立。
- **問題の学年・教科は「わざ」に紐づく。** 「たしざんぎり（算数・小1）」「かんじバリア（国語・小2）」「じっけんフラスコ（理科・小4）」など。わざはレベルアップ・装備・仲間から手に入る。→ 子どもが「強いわざが欲しい」＝「上の学年の問題に挑戦したい」になる導線。

### 4.4 敵の行動と「じゃくてん（弱点）」

- 敵の行動はシンプルなAI（自分の ターンに 通常攻撃60%／わざ30%／防御10%。HP30%以下なら回復わざを優先。防御は 次の ターンまで）。
- effect `status` の 必殺技は あいての うごきを とめる（`turns.statusTurns`（1）× できばえの 倍率 の ターン、敵は その ターン 休む）。ぼうぎょ アップ・ダウンは `turns.buffTurns`（3）ターン つづく。
- 各敵には「じゃくてん」がある。**理科の観察・実験型問題**（§5.2）を「しらべる」コマンドで実行すると弱点属性が判明し、以後その属性のわざが ×1.5。理科の勉強が「敵を調べる」行為として自然に入る。

### 4.5 バトル終了

- 勝利：経験値（主人公＋出撃モンスター）、ゴールド、ドロップ判定、仲間化判定。
- 敗北：ゴールドを 10% 失って最後に泊まった宿屋へ。**装備・仲間は失わない。** 死にペナルティは軽く。
- 逃走：成功率は すばやさ比。ボス戦は不可。

### 4.6 ドロップと仲間化

- `drops: [{ itemId, rate }]`、`recruitRate`（基本 5〜15%）、`xp`、`gold` を敵定義に持つ。
- 仲間化条件のバリエーション：
  - 撃破時の抽選（基本）
  - **HPを 20% 以下にして「さそう」**（問題 score 1.0 だと成功率 ×2）
  - 特定アイテム（県の特産品）を「あげる」（青森の敵にはりんご、など）
- **しんか**：モンスターに `evolution { to, item }` があれば、その どうぐを「バッグ」の画面で つかうと しんかする（レベル・けいけんちは そのまま）。使う数は `count`（省略時 1）。しんか先にも `evolution` があれば、もう一度 しんかできる。例：ネブタン →（ネブタイショウ（青森の中ボス）が かならず落とす「ねぶたの お守り」1 こ）→ ネブタムシャ（必殺技「ラッセラーのほのお」★3 が ふえる）→（「ねぶたの灯り」3 こ。中ボスが かならず、ネブタンが 30% で落とす）→ ネブタイショウ（仲間用の `aomori-nebuta-taisho`。中ボスと同じ見た目・名前だが、ボスの強さではなく しんかするたびに強くなる。必殺技「やまだしとっしん」★2 が ふえる）。
- **東北の しんか**：ネブタンの ほか、東北の通常モンスター 19 体が 1 回ずつ しんかする（例：リンゴロン → リンゴナイト、リュウセンウオ → ドラゴンブルー、ショウギコマンダー → リュウオウコマ（将棋の「成る」））。しんかの どうぐは 1 系統に 1 つで、県の名物の豆知識つき（りんごの 花＝青森県の 県の花、成り駒の しるし など）。**その モンスター本人が 8% で落とし、その県の 県ボスが かならず落とす**。しんかすると ステータスが上がり、属性の ★2 の必殺技（はっぱあらし・うずしお・いわおとし・ほのおのうず・ひかりのや・はばたき）を おぼえる。一覧は docs/05 §6。
- **バッグ**：フィールドの右上「バッグ」（P / B キー）で、主人公と仲間のステータス・必殺技（★）を見て、仲間モンスターと そうびを **バッグの マス** に いれる ⇄ だす、せんとう（バトルで さいしょに出る）を えらび、しんかさせる。**バッグに いれた ものだけ** バトルに 出せる・そうびが きく（いれていない ものは「あずけている」）。
  - マスの数は **主人公の レベル** で ふえる（`settings.bag`：さいしょ 3 マス、2 レベルごとに +1、12 マスまで）。レベルは けいけんち から きまる（`heroLevel`。レベルアップの ステータスの のびは まだ 無いので、敵の レベルは `player.level` の まま）。バトルで マスが ふえると「バッグの マスが ふえた！」。
  - 仲間は **しんかの だんかい ぶん マスを つかう**：しんか前 1 マス・1 かい しんか 2 マス・2 かい しんか 3 マス（`evolution.to` を さかのぼって 数える）。バッグの 仲間は 何体でも バトルに 出て 入れかえできる（3 体の 上限は なくした）。バッグに 仲間が いなければ 主人公 ひとりで たたかう。
  - そうびは 1 こ 1 マス。バッグに いれる ＝ そうびする（同じ部位は 1 つ。入れかえは マスが かわらない）。やくそう・そざい・しんかの どうぐは マスを つかわない（数だけ もてる）。
  - しんかで マスが ふえて 入りきらないときは しんか できない（先に ほかを だす）。仲間に なった モンスターは マスが あれば バッグへ、たりなければ あずける。マスが できる前の セーブで マスより 多く 入っているときは、だすことは できるが いれられない。
  - 画面：左の上に 主人公、その下に 6 マス × 2 だんの マス（仲間は 横に 1〜3 マス、あきは 点線、まだ ひらいていない マスは あく レベル）、その下に あずけている 仲間・そうび。ロジックは `src/core/progression/bag.ts`、画面は `src/ui/field/BagOverlay.tsx`。
- 仲間になったモンスターは **図鑑（ずかん）** に登録。図鑑には県名・モチーフとなった実在の名所／特産品の一言解説（社会科の知識）を載せる。

### 4.7 対戦モード（1対1）

- 「たいせんじょう」（各町にある）で、**自分のパーティ vs 保存済みの相手パーティ** の1対1バトル。
- MVPでは相手はローカルの「ゴーストデータ」（自分の過去パーティ、またはプリセットのライバルNPC）。将来のオンライン対戦のために、**対戦は「パーティ定義JSON 2つ＋乱数シード」を入力にして決定論的に進む** 設計にする（リプレイ・非同期対戦が後付けできる）。
- 対戦中の問題は、対戦者双方の設定学年のうち低い方に合わせる（フェアネス）。

## 5. 問題（学習）システム

### 5.1 大原則：**問題コンテンツとUIは別チームが編集する**

- **問題作成者** は `content/questions/**/*.json` だけを触る。コードは一切触らない。
- **UI担当** は `src/questions/renderers/**` だけを触る。問題の中身は触らない。
- 両者の契約は **問題タイプ（`type`）ごとのJSONスキーマ**（`schemas/questions/<type>.schema.json`）。詳細は `01_ARCHITECTURE.md` と `04_CONTENT_TEMPLATES.md`。
- ゲーム本体（バトル・イベント）は「教科・学年・タグでフィルタして1問ください」と頼み、`QuestionResult` を受け取るだけ。問題タイプが何かは知らない。

### 5.2 問題タイプ（MVPで実装する8種）

「読んで、選択肢を選ぶ」だけにしない。**操作＝理解** になる形を優先。

| type | 教科の例 | UIのイメージ | score の出し方 |
|---|---|---|---|
| `choice` | 全教科 | 2〜4択。選択肢は絵でも文字でも可 | 正解 1.0 / 不正解 0 |
| `picture-word` | 英語・国語（語彙）・生活 | 絵を見て、正しい単語カードを選ぶ（いまはタップ／1〜4 キー。単語を聞いて絵をタップする逆モードは これから）。**日本語訳は出さない** | 一発正解 1.0、2回目 0.5、それ以降 0 |
| `number-build` | 算数 | 数字ブロックを並べて答えを作る／10のまとまりで数を表す／数直線をスライド | 正解 1.0、誤差に応じて減点（数直線） |
| `sort-order` | 国語（文の並べ替え）・社会（歴史順）・理科（成長の順） | カードを正しい順に並べる | 正しい位置の割合 |
| `map-tap` | 社会・生活 | 地図上の正しい場所をタップ（県の位置・川・山） | 距離に応じて 1.0〜0 |
| `experiment` | 理科 | パラメータをいじって結果を観察する疑似実験（水の量と温度、ふりこの長さ、回路のつなぎ方）。**「予想→操作→結果」** の3ステップ | 予想が合っていたら 1.0、外れても操作を完了したら 0.5 |
| `kanji-trace` | 国語 | 漢字をなぞる（書き順判定は緩く、はみ出し率で採点）／読みをひらがなで選ぶ | なぞり精度 0〜1.0 |
| `pair-match` | 英語・理科・社会 | 神経衰弱風にペアを合わせる（絵↔単語、生き物↔すみか、県↔特産品） | ミス回数で減点 |

- 各タイプは **問題作成者がJSONを書くだけで新しい問題を追加できる** こと。UI担当が新しいタイプを追加するときは、スキーマ・レンダラー・サンプル問題の3点セットを追加する。
- 音声：英語の `picture-word` は単語の読み上げ音声（`assets/audio/words/<word>.mp3`）を必須にする。低学年の国語も選択肢の読み上げボタンを付ける。

### 5.3 教科と学年

学習指導要領ベースで、**中学受験・高校受験に効く主要教科** に絞る。

| 学年 | 教科 |
|---|---|
| 小1・小2 | 国語・算数・生活・英語（絵と音でなじむ程度） |
| 小3・小4 | 国語・算数・理科・社会・英語 |
| 小5・小6 | 国語・算数・理科・社会・英語 |

- 問題には `subject`（`kokugo / sansu / rika / shakai / seikatsu / eigo`）、`grade`（1〜6）、`unit`（単元コード。例 `sansu.g2.kuku`）、`tags`（`prefecture:aomori` など県との紐付け）を必ず持たせる。
- **社会科は「マップそのもの」が教材。** 図鑑・NPCの会話・地名・特産品が出題範囲に自然に入る。青森の島で「りんごの生産量1位の県は？」が出るのはズル（今いる場所が答え）で良い。むしろそれが記憶の定着になる。

### 5.4 出題の選び方（アダプティブ）

- プレイヤーごとに `unit` 単位で「習熟度（0〜1）」を持つ（正答率の指数移動平均）。
- わざの学年帯の中で、習熟度が低い単元を **7割**、復習（習熟済み）を **3割** 出す。
- 同じ問題IDは直近20問以内に再出題しない。
- 間違えた問題は「まちがいノート」（図鑑の隣）に貯まり、宿屋で寝る前に「ふくしゅう」すると翌朝ボーナス（HP全快＋小ゴールド）。

## 6. 成長・装備・アイテム

### 6.1 装備スロット

**ぶき／あたま／むね／こし（下半身）／あし** の5スロット。

- 各装備は `stats`（攻・防・速・賢）、`element`（属性耐性/付与）、`skill`（付与わざ）、`setId`（セット装備）を持てる。
- 県モチーフのセット装備（例：青森セット「ねぶたのかぶと／りんごのよろい／ひばのこしあて／つがるぬりのブーツ／マグロずつき（武器）」）を揃えるとセットボーナス。**セット効果は図鑑の解説と一緒に「なぜこれが青森なのか」を1行で出す。**
- **めいさんひんの そうび（県の ごほうび）**：県の 名所スタンプ（にほんちずの ★。特産品の 宝箱も ふくむ）を ぜんぶ あつめると、その県の 名産品の そうびを 1 つ もらえる（カットイン「ごほうび ゲット！」）。ふつうの そうびと 同じく バッグに いれると そうびでき、HP・ぼうぎょ などが あがる。**着ると 主人公の 絵が 大きく かわる**（歩く絵・バトルの絵。主人公の コマは 24×32 で、体より 大きな かぶりもの・きぐるみを 描ける）。部位の ちがう ものは いっしょに 着られる。id は `<県>-meisan-<名産品>`（`areaOrigin` が その県）、ロジックは `src/core/progression/meisan.ts`、絵は `src/scenes/art/costumes.ts`。いまは 北海道＝夕張メロンの かぶりもの（あたま）・青森＝青森りんごの きぐるみ（むね）・秋田＝曲げわっぱの すねあて（こし）・岩手＝南部鉄器の ブーツ（あし）。

### 6.2 入手経路（全部を実装する。子どもの「集めたい」に複数の出口を作る）

| 経路 | 仕組み |
|---|---|
| モンスタードロップ | `drops` の抽選 |
| 合成 | 町の「かじ屋」で `recipes.json` に従い素材＋ゴールド → 装備。**素材は県の特産品**（りんご×3＋てつ → りんごのよろい） |
| イベント達成 | 名所イベント（§7）の報酬 |
| ショップ | 県ごとに品揃えが違う。値段は `content/prefectures/<code>.json` の `shop` |
| ミッション | 掲示板ミッション（「ねぶたキャップを3体たおす」「算数のわざで5回かんぺきを出す」）の報酬 |

### 6.3 レベルと学年フィルタ

- レベルは通常のRPG通り（経験値テーブルは `content/balance/xp.json`）。
- **学年設定**（保護者メニューで変更可）：出題の学年帯を決める。「下の学年の問題も混ぜる」「上の学年に挑戦する」のトグルあり。ゲーム進行（島の解放）とは独立。

## 7. イベント（名所・特産品）

- 各県 2〜4 個。名所に到着するとカットイン → 短い会話 → **その名所に合った問題タイプ** → 報酬。
- 例（青森）：
  - **三内丸山遺跡**：発掘ミニゲーム。土を掘る（タップ）と土器のかけらが出て、`sort-order` で「土器→古墳→…」の時代順並べ替え（社会）。報酬：「じょうもんのくび飾り（あたま）」。
  - **りんご園**：りんごを収穫してカゴに入れる `number-build`（算数：3+4=7個、かけ算九九で箱詰め）。報酬：りんご（素材）×N。
  - **津軽海峡**：船で渡る途中、`picture-word` で海の生き物の英単語（英語）。報酬：「マグロずつき」レシピ。
  - **十和田湖**：`experiment` で「水の温度と季節」（理科）。報酬：「みずのかけら」。
  - **恐山**：ちょっと怖い（子どもが好きな程度の）雰囲気。`kanji-trace` で「石」「山」「風」をなぞって封印を解く（国語）。報酬：ヤミ属性の仲間候補「イタコドリ」出現。
- イベント定義もJSON（`events`）。会話文はJSONにテキストとして持ち、コードに書かない（後で世界編に差し替えるため）。
- **名所は近づくだけで始まる**（★ の看板のまわり 1 マスに入ったとき）。看板は最初から立っているが、**見つけるまでは ★ が灰色**（名前の札はいつも出さない）。はじめて着くと カットイン「めいしょ はっけん！」→ ★ が白くなり上に「！」（チャレンジがまだのしるし）が出て **名所スタンプ**（図鑑の名所 `dex.motifs`）→ 会話 → 「ちょうせん する？」（はい／いいえ。いいえなら次に来たときにまた。カットインは最初の 1 回だけ）→ 問題 → 報酬 → ★ が金色に（`progress.eventsDone` に記録。`once: false` のイベントも記録する）。`once: true` のイベントは 1 回だけ。終わったあとは看板をしらべると解説だけ出る。
- イベントの無い名所・特産品（白神山地・弘前城・龍泉洞・わんこそば・南部鉄器など。1 県 8〜12 か所）も、近づくとカットインが出て ★ が金色になり（チャレンジが無いので見つけたら終わり）、一言解説とスタンプがもらえる。場所は `scripts/data/geo.ts` の `LANDMARK_SPOTS`（実在の緯度経度。特産品は産地。離島の範囲に入る場所は離島マップに立つ）。にほんちずでは、見つけていない名所は「？？？」と出る。
- content に書いた問題タイプがまだ無いときは、教科・学年の合う問題で出す。どれも無ければ「じゅんびちゅう」と出して score 0 の報酬（ゲームは止めない）。

## 8. UI/UX の必須要件（小学生向け）

- **全テキストにふりがな**（ルビ）。フォントはドットフォント **PixelMplus12**（12px のマス目。**文字の大きさは 12 / 24 / 36 / 48px だけ**。14px や 22px などにするとドットがにじみ、ドット絵の字ではなく「解像度が低い字」に見える）。フィールドの看板は、ふりがなを付けられないので **ひらがな** で書く（読みは RubyText のルビから作る）。学年設定で「漢字表示レベル」を切替（小1設定ならすべてひらがな）。**まだ習っていない漢字（学年別漢字配当表で 漢字表示レベルより上の学年の漢字・小学校で習わない漢字）を ふくむ ことばは、ルビを振らずに ひらがなで出す**（ことばごと開く。まぜ書きにしない）。ただし地名・名前（`content/i18n/proper-nouns.json` と「〇〇市・〇〇町」など）は漢字＋ルビのまま。ルビを付けていない漢字（漢字の問題で問う漢字）は いつも そのまま出す。配当表は `content/i18n/kanji-grades.json`（2020 年度からの 1026 字）。
- 文字より先に **アイコンと色** で伝える。ボタンは最小 48px。
- 操作：キーボード（矢印＋Z/X）・マウス・タッチの3系統すべて対応。タブレットの横持ちを基準解像度にする（**基準 960×540、整数倍スケール**、ドットがにじまない `pixelArt: true`）。
- 読み上げ：低学年向けに会話文の読み上げボタン（Web Speech API で可。音声ファイルは英単語のみ必須）。
- 失敗を責めない。不正解時の表現は「おしい！」「もういっかい！」。赤い×は使わない。
- 保護者メニュー（設定の奥、簡単な足し算で開く）：学年設定、プレイ時間の記録、単元ごとの習熟度グラフ、セーブデータのエクスポート/インポート（JSON）。
- **ログイン不要、個人情報を取らない。** セーブは端末内（`localStorage` + `IndexedDB`）。

## 9. 将来拡張のために最初から守ること

- 「日本編」は `content/world/japan.json` を起点とする **1つのワールド**。世界編は `content/world/world.json` を追加するだけで差し替えられるよう、コードは「ワールド→島（地方）→エリア（都道府県）」の3階層を汎用に扱う。「都道府県」という語はコード上では `area`、「地方」は `island`。
- テキストは全部 `content/**/*.json` か `i18n/ja.json`。コードにハードコードしない。
- 問題タイプは **プラグイン登録制**。新タイプの追加でバトル・イベントのコードを変更しない。
- 対戦は決定論的（乱数シード入力）。
- 素材（画像・音）はすべて `assets/` 直下で、命名規則は `03_IMAGE_PROMPTS.md` §1 に従う。

## 10. MVP の完成定義（Definition of Done）

以下がブラウザ（Chrome 最新）で通しで遊べること：

1. タイトル → 名前・見た目・スターター選択 → 東北の島に上陸。
2. 青森エリアのフィールド・町・ダンジョンを歩ける。エンカウント・宝箱・NPC会話が動く。
3. バトルで 5コマンド全部が機能し、わざ選択で 8 種の問題タイプのうち **最低 4 種**（`choice / picture-word / number-build / experiment`）が出題される。
4. ドロップ・仲間化・レベルアップ・装備5スロット・合成・ショップ・ミッションが動く。
5. 青森の県ボス撃破 → しるし入手。残り5県は **データを入れれば動く状態**（うち最低1県（宮城 or 秋田）はデータ投入済み）。
6. 地方ボス（東北）撃破 → 「次の島はまだ結界の中」表示。
7. 対戦場でゴーストデータとの1対1対戦ができる。
8. セーブ／ロードが動き、リロードしても続きから遊べる。
9. 問題作成者が `content/questions/` にJSONを1つ追加するだけで、コードを触らずゲーム内に反映される（実証すること）。
10. 全テキストにふりがなが付き、タッチ操作だけでクリアできる。
