# 第四章「北陸の水鏡」シナリオ

## 章の問い

北陸編では「記録の空白を、もっともらしい想像で埋めてよいのか」を扱う。
残った痕跡、複数の独立した資料、復元した箇所、まだわからない箇所を分け、
新しい証拠が見つかったときに直せる知識を作る。

## 導入

関東の黒い情報網がほどけると、日本海に水鏡が現れる。水鏡は消された文字の跡を
映す一方、空白へ人々が望む「きれいな答え」を勝手に書き足していた。
主人公たちは証拠・予想・未確認を色分けして復元する旅へ出る。

## 四県の復元調査

- 新潟: 信濃川の水位記録、川岸の土、日記、収穫記録を重ねて空白を調べる。
- 富山: 消えた薬売りの訪問先を、道順、薬箱、受取人の手紙からたどる。
- 石川: 修復した部分を隠さず、元の筆跡と後世の手を区別して残す。
- 福井: 恐竜化石から確実な部分と比較による予想を分け、直せる復元図を作る。

町、名所、中ボス、県ボス、歴史人物の節目で、空白を急いで埋めない姿勢を
見聞帳へ記録する。シオリの会話も攻略段階に応じて変化する。

## 地方ボスと第三者の痕跡

地方ボス「カガミウツシノミコト」は、欠けた記録を理想的な像で埋め、予想を
本物の記憶へ変える巨大な水鏡である。浄化後、壺の設計図を破ったのは主人公でも
ミチルでもない第三者であり、その人物は自分の痕跡を消す方法を知っていたと判明する。

主人公たちは第三者の正体を急いで決めず、破れた紙の端や筆跡を集める。
甲信の山へ飛んだ同じ紙片を第五章への導線として残す。
