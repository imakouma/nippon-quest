# 理科教材の図解とスマホ可読性

ユーザーの「理科の問題も同じように見て、図や画像を入れ、スマホで見やすくし、本番反映まで」という指示に基づく。基点 d0338832、専用ブランチ codex/rika-visual-readability。

対象は理科689問（小3:118、小4:172、小5:209、小6:190）。既存画像または実験表示251問、文字中心438問。全問の問題文・回答・既存画像を監査して、図が学習条件や対象の理解に役立つ問題へSVG教材図を追加する。図示すると正答を直接表示してしまう語句・安全行動の確認は文章を維持する。元の条件が欠落している問題は推測で復元せず、資料を追えるものだけ修正する。

デザインは既存の白い教材面・濃い輪郭・紺の問題枠を維持。Referoの前回の研究方針（Touch & Mobile、Images、Forms）を継続し、360〜400px程度で意味が読める短いラベル、大きな器具・生物・実験配置を使う。図の色だけに意味を依存させない。図中の文章量を抑え、問題文のふりがなと読み上げを維持する。既存の共通questionViewportで縦横対応し、個別スクロールや非表示による検査回避をしない。

変更先はcontent/questions/rika、assets/questions/rika/visuals、再生成スクリプト、全問レビュー記録、単体/E2E。schema、契約、保存形式、採点、依存は維持する。正答・選択肢を固定した署名を検査し、図にない条件を勝手に追加しない。SVGは既存の算数図生成スクリプトの書式（asset/attachとXMLエスケープ）を使う。

手順: (1)全問監査・図の対象を決定 (2)回路/磁石などの代表図と失敗する契約検査 (3)学年ごとの図の追加・再生成・内容確認 (4)画像の実表示/スマホ可読性/全問4サイズ監査 (5)check:full・独立レビュー (6)PRとCI・mainマージ・公開デプロイ・本番と4174の「問題レビュー」確認。

検査: pnpm exec vitest run tests/unit/rikaVisuals.test.ts、pnpm exec playwright test tests/e2e/battle-question-audit.spec.ts tests/e2e/question-viewport.spec.ts、pnpm test:e2e:mobile、pnpm test:e2e:audit、pnpm check:full。390×844と320px幅を含めて文字・図・ボタンの欠落なし、代表問題の本文18px以上と図幅280px以上を確認する。変更後Graphifyはコードのみで更新。学習内容の疑義は公的な資料で確認する。

戻す場合は今回の図追加コミットをrevertできる。データ移行や外部サービス追加はない。物理端末は未接続のためブラウザのスマホ相当検査と公開ページ確認を行う。

種の形・火山灰の粒・昆虫の足の数などは、図を観察して答えられるようにする。読み上げも同じ観察情報を伝えるが、問われる器官や現象の名前は追加しない。
