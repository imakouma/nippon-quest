# 公開版のフォルダ構成読み込み警告

- 対象: 問題レビューのフォルダ構成 API の初回読み込み。
- 原因: GitHub Pages はローカル保存用 POST API を提供せず、405 の HTML を返す。
- 修正: 初回読み込みの 404 / 405 だけ標準フォルダの閲覧へ戻す。状態を null に保ち、保存・追加・移動を許可しない。
- 保持: その他のエラー、不正な応答、書き込み失敗は警告する。保存ファイルや API の検証・競合検知は変更しない。
- RED: 404 / 405 のブラウザ再現テストが警告表示により失敗。
- GREEN: 静的公開先、異常応答、保存失敗、追加・削除・復元の 8 テストに合格。
- Mutation: 読み込み条件を反転すると保存エラー検査が失敗。実装を復元済み。
- レビュー: 別モデルで呼び出し元・既存の null ガード・サーバー検証を確認し、指摘なし。
- 公開版は標準フォルダの閲覧用。フォルダ構成の編集保存は引き続きローカル環境で行う。
