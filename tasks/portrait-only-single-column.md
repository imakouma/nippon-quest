# 通常2列、スマホ縦だけ1列

ユーザーの訂正に従い、常時1列を撤回する。通常は一覧:レビュー=1:1.8の2列、幅600px以下かつ縦向き・coarse pointerの端末のみ1列とする。PCの狭いウィンドウとスマホ横画面は2列。

文字・余白・ボタンの共通倍率と相対単位は維持する。列配置の変更はユーザー指定の例外とし、文字サイズの別ルールは追加しない。問題renderer、保存、採点は変更しない。

検査は縦横回転と600/601px境界、PCの狭い縦画面、各列配置内の26種類×縦横の連続比率、既存の検索・編集・問題viewportを対象とする。スマホ横で1列のままという旧動作を修正前にE2Eで再現した。

検証結果: Android/Chromium 16件、Playground・問題viewport 47件、`pnpm check:fast`、テストの型検査が成功。アプリ内ブラウザで2列表示を確認し、独立レビューで必須修正なし。実機端末は未検証。
