# 小5算数の視覚化

基点 `2646b7b0`、ブランチ `codex/math-fruit-pictogram`。
小1〜小4と同様に小5を改善するという継続指示に基づく。

333問を全件確認。体積・比例・平均・速さ・割合・円・角柱には、具体物、立体、帯、表を追加する。
分数の計算は同じ大きさの全体を等分した図で示す。明確な式のある問題だけ、連結された分数回答を分子・分母の入力欄へ分ける。
条件欠落や式と正解の不一致は推測で補わず監査に記録する。既存の図、数式自体を学ぶ練習は維持する。

参照は既存の小1〜小4教材図とRefero craft-detailsに固定。白地、濃い輪郭、数量に比例した寸法を使う。
答えの数値は新しい図へ印字しない。既知の条件、未知の量、単位を区別し、読み上げ用説明を付ける。
変更先は小5問題JSON、SVG、生成スクリプト、全件監査、画像CSS、テスト、制作根拠、生成カタログ。
契約・スキーマ・依存・保存形式は変更しない。

Graphifyのコードのみの依存確認を実施。検査は対象単体テスト、全図4サイズE2E、既存viewport回帰、check:fast、tools/tests型検査、全test、validate:content、build。
4184の問題レビューで正答・誤答と狭い画面を確認し、スクリーンショットを残す。

完了: 全件監査、図版追加、採点・表示の回帰検査、実画面確認を実施。詳細は `sansu-g5-visual-walkthrough.md`。
