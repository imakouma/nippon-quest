# 国語の教材図とスマホ可読性

## 合意された範囲

国語を全学年確認し、文字だけでは場面・関係・文章の構成を理解しにくい問題に教材図を加える。既存の問題レビューと promptImage、共通 questionViewport を使う。読み書きそのものを問う問題には正解の読みや字形を示す装飾図を追加しない。

## 図版の基準

既存の算数・理科・社会の教材図を参照し、白地・濃い輪郭・大きな短いラベルを使う。原則480px幅のコンパクトなSVGとし、390px縦画面で本文18px、図幅280pxを目安に検査する。場面図には問に必要な条件だけを示す。答え・選択肢・問題IDを変えず、代替説明でも正解を漏らさない。

- 4,665問を判断台帳に記録。55問に35枚のSVGを追加し、既存6問の文脈・条件を明確化した。正答・選択肢・IDは全件不変。

- 独立した相互レビューで代替説明による助詞の答え漏れ、花の色、鳥の描写、切手の識別性を修正。
