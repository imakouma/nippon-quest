# 図鑑の初回表示を高速化

図鑑の画像は、選んだ地方の行と詳細欄を描画するときに用意する。学習ロードマップの組み立ては、学習タブの表示モデルが必要な場合に限る。ゲーム起動時の事前生成は追加していない。

同じローカル Chromium で、新しいブラウザコンテキストから図鑑を開いて計測した。クリックハンドラの同期処理は修正前が 469〜475 ms、修正後が 34〜40 ms。クリック中の Canvas 画像生成は 540 回から 27 回に減った。この計測にはブラウザの描画や画像のネットワーク転送時間は含まない。

モンスターと特産品の両図鑑で、地方切り替え、詳細、番号、矢印キー操作を確認した。既存のブラウザテストが 960 px と 640 px のスクリーンショットを test-results に保存する。アプリ内ブラウザでも北海道の初期表示と未発見シルエットを確認した。実機のスマートフォンでの速度は未計測。
