# 算数以外の単元内学習順

## 目的と範囲

ユーザー依頼の「算数以外も全学年、同じ単元の中で基礎→標準→応用」を実装する。
算数の並べ替え計画の追加仕様。国語622・漢字4043・理科689・社会469・生活152・英語155の6,130問を対象にする。
存在する学年を全件確認する（国語・漢字1〜6、理科・社会3〜6、生活1〜2、英語3〜6）。
基点は統合ブランチ b4d427dc。問題本文・正答・ID・所属単元・フォルダ割当・算数学習順は保持する。

## 成功条件

- 各問題の内容を踏まえ、用語/認識の基礎→直接読み取り/操作→理由/比較/複数条件/活用の順になる。
- 同じ段階内も必要な前提から先に置く。同難度は既存順を尊重し、応用が無い単元へ架空の段階を設けない。
- 全対象IDを一度だけ登録し、全単元・全学年を監査記録で追跡できる。
- 単元をまたぐ検索結果や独自フォルダでは、既存の単元の表示位置を保ち、各単元の問題だけ並べ替える。
- 算数学習順は既存の mathReviewRank を維持する。保存ファイルとゲームの抽選順は変更しない。

## 実装

content/review に教科別の単元・学年・3段階のID配列を置く。
既存 QuestionList の絞込後、200件制限前の箇所へ純粋な並べ替え関数を接続する。
関数は src/tools に置き、QuestionBase・Preact非依存の配列操作を使う。
書式は既存 mathReviewOrder.ts 同様の型付き TypeScript と JSON。依存追加・契約/schema変更なし。
問題内容に不整合を見つけた場合は監査ノートに記録し、順序変更と混ぜない。
