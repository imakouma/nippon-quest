# 分岐・合流型の学習スキルツリー

## Phase 1: グラフ基盤

- [ ] 下→上の分岐・合流と3前提AND条件の失敗テストを追加する。
- [ ] 決定論的な階層レイアウトを純粋関数へ分離する。
- [ ] 親を下、発展単元を上に配置し、同階層の線交差を重心ソートで減らす。
- [ ] `pnpm vitest run tests/unit/roadmap.test.ts`

## Phase 2: スキルツリーUI

- [ ] ロック中の前線ノードを選択可能にし、開始は不可のまま条件詳細を表示する。
- [ ] `達成数 / 前提総数` と未達前提を詳細パネルへ表示する。
- [ ] 48px以上の操作領域を持つ円形オーブへ変更する。
- [ ] 選択経路、達成済み経路、未達経路を連続線と明度で区別する。
- [ ] 学年・学期フィルタでも直接前提コンテキストを残す。
- [ ] 20〜160%ズーム、パン、ピンチ、現在地中央寄せを維持する。

## Checkpoint: UI

- [ ] 100%で縦の主幹、左右分岐、合流が追える。
- [ ] 20%で長文ラベルを隠し、ツリー全体を見渡せる。
- [ ] 960×540と640×540で操作部品と詳細パネルが重ならない。

## Phase 3: 最初の教材範囲

- [ ] 小学1年の国語・算数へ出典付きの分岐・合流を追加する。
- [ ] 小学1〜2年の生活・補助英語へ適用可能な前提関係を追加する。
- [ ] 学年限定のロードマップ監査を追加する。
- [ ] 確認範囲に参照切れ、循環、逆学年線、孤立単元がない。

## Phase 4: 検証と引き渡し

- [ ] focused unit / E2Eを通す。
- [ ] lint、architecture、test、content、curriculum、buildを通す。
- [ ] 添付画像とReference lockに照らした視覚QAを行う。
- [ ] Walkthroughと確認スクリーンショットを更新する。
- [ ] Graphifyを更新する。
- [ ] 独立コミットと4174の最新版プレビューを残す。

## Follow-up

- [ ] UI確認後、全学年・全教科を学年単位の小さい教材バッチで整備する。
- [ ] 最終的に `pnpm audit:roadmap-graph --strict` を通す。
