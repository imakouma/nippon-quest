# 小3〜小6 国語の視覚補助

対象は `content/questions/kokugo/g3`〜`g6` の 3,566 問。判定台帳は `scripts/data/kokugo-g3-g6-visual-review.json`。

問題文にある具体的な場面を 18 枚の独自 SVG で描き、21 問に追加した。文法は魚と水そう・本・玉・走る動作・雲などを描き、主語や修飾先の正答ラベル・矢印は付けない。接続詞は二つの場面の間を空欄に保つ。敬語は話し手・相手と動作を示し、敬語の正答は書かない。議論の役割名も空欄にする。

漢字の読み・書き取り・筆順、表記の比較、選択肢の表現そのものを判断する問題には、正答の読みや意味を先に示す装飾を加えない。本文にない物語の情景を推測して補わない。

- 図は 480 × 240、ラベル 24px 以上。横長の余白を抑え、共通 questionViewport で縮小する。
- `promptSpeech` は元の読み上げ文を保ち、場面説明だけ追加。二度実行しても説明を重複させない。
- 生成スクリプトが ID・形式・学年・単元・正答・選択肢の不変性と、一意な問題への対応を検証する。
- 実行済み: 生成スクリプト再実行、ESLint、Prettier、全 SVG の XML・最小フォントサイズ、台帳の全件対応。
- スマホの実画面・全件検査・本番反映は統合担当で確認する。

## 内容監査で見つかった条件不足

21 問の図示、3,523 問の文字維持、19 問の `needs-source`、3 問の `clarified-text` に区別した。`needs-source` は改善済み扱いにしない。個別 ID と理由は台帳に記録した。

- 小4の修飾語2問は、同じセットの主語・述語問題に載る「白い雲が青い空にゆっくりと広がる。」を設問に補った。
- 小6の「見る」の尊敬語は「見られる」「ご覧になる」の双方が成立したため、「特別な言い方」の条件を加えた。正答・選択肢は維持。
- 未提示の読解本文に依存する19問は、物語や説明文の原文確認が必要。本文を推測して図を作らない。
- 「絵がほめられた」の修飾語、様子を表すこそあど言葉、三字熟語の3問は、人物・直後の名詞・「保健」＋場所という条件を明記し、正答が一意になるよう修正した。正答・選択肢は維持し、解説も条件に合わせた。
