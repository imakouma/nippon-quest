# 全国地域進行 Implementation Plan

## Dependency order

`県コンテンツ設計 → 地理seed → マップ生成 → データ監査 → E2E → 次地方`

## Thin slices

1. 全国で再利用する地域データ監査テストを追加する。
2. 東北5県へ地域・関所・出現表・seedを追加し、マップを再生成する。
3. 東北の生成マップと代表プレイ経路を検証する。
4. 同じ単位で残り地方を順次追加する。
5. 全国監査と必須検査を通す。

## Risks and mitigation

- 地域境界が町や入口を孤立させる: 生成後の到達性検査と代表E2Eを地方ごとに実行する。
- ぬしと既存ボスの役割重複: 既存進化系最終形を優先し、県ボス・中ボス・裏ボスは使わない。
- 通常敵が消える: 進化前の野生網羅テストを全国で実行する。
- 大量差分でレビュー不能になる: 地方ごとにコミットし、各地方を独立してgreenに保つ。
