# 小2算数の視覚化・完了記録

## 変更内容

小2算数320問の本文・入力テンプレート・選択肢・画像参照を監査した。
89問を改善し、62枚の自己完結SVGを追加した。内訳は次の通り。

| 判断         | 問題数 | 対応                                                       |
| ------------ | -----: | ---------------------------------------------------------- |
| 視覚化       |     89 | 具体物・絵グラフ・時計・目盛り・関係図を追加               |
| 既存図を維持 |     68 | 分数・図形・ものさしなどの既存図を利用                     |
| 記号の練習   |     47 | 数字・単位記号・式を読む学習として維持                     |
| 原資料確認   |    116 | 式や問題条件が欠けている既存問題。推測による復元は行わない |

全問の理由は `scripts/data/sansu-g2-visual-review.json` に記録した。

- 給食・外遊び12問は丸印を人の絵へ置換し、「絵1つ＝1人」を明記。25枚の投票カードにも人の絵を添えた。
- かけ算はりんご・あめ・人を1人分や1袋分ずつ囲み、数とまとまりが対応する図にした。
- 牛乳パック・缶・ボトル・紙の形を選択肢へ追加。時計、時間の線、長さ・かさの目盛りも追加。
- 位取りは千・百・十・一のまとまり、文章題は増減・差・倍・既知の部分と未知の部分を図示。
- 外遊びの3問は、既存解説に明記された「最少・最多・比較」の問いを本文へ戻した。
- 正解・タイプ・ID・学年・単元を全320問で維持。隔離状態と人による公開承認も変更していない。
- 表示は既存choice/text-inputと共通viewportを使用。小1の教材画像用CSSの適用先を小2にも広げた。
