# Implementation Plan: 小学1年生の算数 UI 改善

## Overview

承認済み仕様のうち、低学年算数の数値入力、10のまとまり、数直線の3動線を既存レンダラー内で改善する。問題データ、採点契約、スキーマ、英語問題は変更しない。

## Architecture Decisions

- 数値テンキーは `TextInputView` の補助入力として実装し、既存の `input`、貼り付け、物理キーボード、Enter操作を残す。
- 数ブロックと数直線は `NumberBuildView` の表示だけを足し、`numberBuildScore` と payload は変更しない。
- 新規コンポーネント・依存・画像は増やさず、既存CSSと短い純粋関数だけを使う。

## Dependency Graph

純粋判定・目盛り計算 → レンダラーUI → 共通CSS → E2E・実ブラウザ確認

## Risks and Mitigations

| Risk                           | Impact | Mitigation                                               |
| ------------------------------ | ------ | -------------------------------------------------------- |
| テンキーで問題枠が縦に溢れる   | High   | 3行×4列の小さい構成と狭幅CSSを実画面で検証する           |
| 数値以外の回答へテンキーが出る | High   | 正解候補を正規化後に厳密判定し、文字回答の回帰E2Eを残す  |
| 目盛り数が多すぎる             | Medium | 20step以下だけ全表示し、それ以上は間引く                 |
| 既存採点が変わる               | High   | score関数とschemaを触らず、代表問題の結果をE2Eで確認する |
