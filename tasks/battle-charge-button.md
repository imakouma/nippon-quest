# チャージボタンの配置変更

## 仕様とデザイン方針

- 通常技4枠とチャージ技2枠の編成・消費ルールは維持する。
- 通常技を基本表示とし、技一覧の左上の独立ボタンでチャージ技に切り替える。
- 教科ゲージはチャージボタンの枠に統合する。2教科なら左半分・右半分を使い、切替だけでは行動しない。
- ゲージ不足でも一覧は確認でき、使えない技は選択を実行しない。
- 仲間の技も既存どおり利用でき、消費ゲージの有無で表示を分ける。
- メニューを閉じると通常技表示に戻す。表示とキーボードの対象を一致させる。

## 参照と判断

| 判断                             | 根拠                                                         |
| -------------------------------- | ------------------------------------------------------------ |
| 技一覧に隣接した独立ボタン       | ユーザーのテラスタルボタンの位置という指定と切替方式への回答 |
| 黒地・白枠・ドット文字・教科色   | 既存NIHON QUEST戦闘UIを主方向として固定                      |
| 星の印と丸みのある独立ボタン     | 通常の技の行と区別し、特殊操作を目立たせる                   |
| 文字付きの準備状態・フォーカス枠 | Refero同梱craft-detailsの色以外の状態表現、キーボード操作    |

Referoライブ接続は使用せず、ユーザー指定の配置、既存UI、同梱のcraft参照を用いた。

## 実装順序

1. 表示切替・不足時の選択防止・キーボード対象の回帰テスト。
2. チャージ操作とゲージをHPから分離し、共通の表示対象で操作する。
3. check:fast、関連テスト、実画面の通常／チャージ／小さい画面を確認する。

## 追加調整：枠にたまる教科ゲージ

- 独立した「ゲージ」枠と0/100などの数値表示を撤去し、旧GaugeColumnと専用CSSも削除。
- 白いボタン枠を教科数で等分し、各教科の蓄積量に応じて教科色を重ねる。現在の2教科は左が国語（赤）、右が算数（青）。1教科は全周、仲間の技で増える場合も全教科を残す。
- 教科アイコンをボタン内に置き、正確な数値は読み上げ用の説明として維持。動きを減らす設定では枠の補間アニメーションを止める。
- 消費直後の減少と0〜最大値へのclampを維持。満タンの技も使用可能判定の閾値に含め、技一覧をまだ開いていなくても「つかえる」を正しく表示する。
