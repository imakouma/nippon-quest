# 小6の残件復元と本番反映

作業ブランチ codex/g6-source-repairs-release。ユーザー指示により、残り21問と前回未統合の配信・CI設定を本番反映する。

取り込み記録のnode/sourceIndexを旧教材データへたどり、ローカルの questions.json にある contentId / section / questionNumber / question_id で21問を照合した。20問で失われたqtext_templateまたは帯分数の表記を確認。代表値1問は元々条件の欠落がない監査の誤判定だった。

20問の条件を復元し、等分・比・対称・体積・比例反比例を既存の自作SVG生成ヘルパーで図示する。分数6問は既存の分子・分母の2欄に直す。2つの空欄を選ぶ3問は選択肢も同じ2語形式にそろえる。問題ID・単元・正解の数学的な値を維持し、既存193問の回帰を守る。

変更先: 小6のJSON、画像、生成スクリプト、原資料照合記録、レビュー、単体・表示検査、生成カタログ。スキーマ・依存・保存形式は変更しない。未統合の起動bundle軽量化、生成件数整合、画像CI設定も最新mainへ合わせる。公開問題レビューを有効にしたPR #82を保持する。

検証: 復元条件・分数採点・図の寸法/数量の単体テストを先に失敗させる。生成再実行の同一性、全小6図の4サイズ表示、入力の正誤と解説を確認。check:full、PR CIを通してmainへマージし、GitHub Pagesのdeploy-pages成功と公開URLの問題・画像を確認する。

不具合時はこの修正コミットをrevertして前の公開版へ戻せる。データ移行やセーブの変更はない。
