# 正規プレビューの配信元固定

4174が別worktreeの古いビルドに置き換えられ、漢字の線幅・判定が未反映になる問題への修正。

- `pnpm nrd` はGitのworktree一覧から統合ブランチのcheckoutを探す。呼び出し元の作業版は配信しない。
- Viteで4174の開発サーバー起動と、統合checkout以外からの4174プレビュー起動を拒否。
- 統合コミット・配信元・ビルド更新時刻の印を確認し、不一致ならビルド成功後に配信。並行リクエストは一つのビルドを待つ。
- ビルド失敗・未コミット変更・ビルド中のコミット変更はエラーとして停止し、古い版への黙った切替をしない。
- 正規サーバーは起動済みなら再利用。別サーバーのkillやポートの自動変更はしない。
- `/__integrated-preview` と `X-NQ-Commit` で配信元・コミットを確認できる。

作業worktreeの解決・起動拒否・統合ブランチ不在を一時Gitリポジトリで検証。実際の作業ブランチから4174起動がエラーになること、lintとtools型検査の成功を確認。

このガードを含まない古いcheckoutや任意の外部プロセスによる強制killまではOS権限上禁止できない。既存の正規サーバーをkillしない運用をAGENTS.mdに明記。統合後に開き直すと最新版を配信するが、入力中の画面を強制リロードはしない。
