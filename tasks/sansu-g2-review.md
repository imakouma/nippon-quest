# 小2算数：学ぶ順・内容・解説の監査と修復

## 対象と受入条件

既存323問（固定320問＋ランダム3定義）を全件点検。既存ID・unitを維持し、解ける条件、正答、学年適合、解説、図の根拠を確認する。固定問題に理由を持つ解説を付け、不足した理解活動をオリジナル図付きで補う。全IDを学ぶ順へ一度ずつ配置する。共有UI・生成manifest/catalog・権利台帳の統合は親担当。

工程は原資料照合→式・文章条件修復→解説補強→不足問題追加→学習順→算術/スキーマ/実画面検証。ユーザーの実装・統合指示を承認として実行した。`using-agent-skills`、incremental-implementation、code-review-and-quality、Ponytail fullを適用。Graphifyは `graphify update . --no-cluster` でコード専用抽出を実施し、問題→契約/renderer→playgroundの境界を確認。契約、描画コード、学習記録の構造は変更しない。

## 教育上の根拠と表示順

- [文部科学省・平成29年告示小学校学習指導要領解説 算数編](https://www.mext.go.jp/content/20211102-mxt_kyoiku02-100002607_04.pdf)：小2の数と計算、図形、測定、データの活用を照合。分数は具体物の等分、時刻・時間は単位と関係が中心。PDF全文取得には時間切れがあったため、公式URLの検索インデックスで該当節を確認。
- [東京書籍2024年度小2年間指導計画・略案](https://ten.tokyo-shoseki.co.jp/text/shou/sansu/data/sansu_keikaku_ryakuan_2.pdf)：表示順の基準。表/グラフ、加減筆算、長さ、3桁、かさ、時刻、計算の工夫、拡張筆算、平面図形、かけ算、4桁、m、加減の関係、分数、箱の形。
- [啓林館2024年度小2年間指導計画](https://www.shinko-keirin.co.jp/keirinkan/sho_r6/sansu/file/sansu_guidance_plan02.pdf)：内容と前提関係のクロスチェック。時刻を早期に置くなど東京書籍と順序差がある。

学習指導要領は年間の唯一の順番を規定しない。表示順は東京書籍に近い推奨順であり、全教科書に同一でも教科書そのものでもない。確認対象は公開年間指導計画で、教科書全ページを精査したとの主張はしない。問題数がある既存単元でも、定義・手順暗記に偏った活動を補う。

## 結果

- 合計335問（固定332問＋ランダム3定義）。既存165問を変更、うちpayload131問、解説98問。新規12問にはすべて理由付き解説を付与。
- 学ぶ順は20グループ。旧unitを保持したまま原資料の小節・設問順を基礎にし、九九は意味→5/2/3/4→6/7/8/9→計算練習を明示。ランダム練習を末尾へ配置。
- 原式・数列・漢数字・文章条件の欠落を元資料から修復。92件は復元式から独立算術評価して正答と照合。計算の答えから式を逆生成していない。
- 潰れた筆算数字列、`require`/`bcancel`残骸を具体的な繰上げ・繰下げ解説へ修復。表・図形・分数・逆思考・位取りの説明も補強。
- 時間の7問は元の問題の単なる復元ではなく、小2範囲へ意図的に再設計。時刻を読む、同じ分で1時間差、正午までの整数時間、1周60分へ改稿した。正答7件を変更。`sansu-g2-time-scope.json` に旧新正答と理由を記録。
- L/lが両方有効になり得る単位選択肢2問を修正。容量2問には実際の容量表示を追加し、一般的な容器名だけで容量を断定する曖昧さを除去。

## 監査記録

- `sansu-g2-audit.json`：335IDと原資料の参照・判定。回答全件をアプリ上でも確認する。
- `sansu-g2-repairs.json`：変更フィールド、参照、理由、復元式と独立検算。元問題文/解説全文の二重保存はしない。
- `sansu-g2-additions.json`：新規ID、単元、学習観点、原創SVGへの対応。
- `sansu-g2-time-scope.json`：7件の意図的な学年範囲修正と旧新正答。
- 全図解判断は `scripts/data/sansu-g2-visual-review.json` に335件。SVG図解対象103問。初期128固有画像をブラウザの11枚のシートで確認し、その後の修正図を再確認。

原資料照合は `imports/legacy-questions/staged.json` の nodeId/sourceIndex → 自治ゲーム元 `mathGrade2EboardQuiz.ts` の contentId/subSectionOrder/questionNumber → 既存ローカルscrape `questions.json` の同キー。独立評価の値が原正答と合わない場合は中断する方針とし、復元計算では不一致を検出しなかった。

## 資産の制作根拠・権利

`assets/questions/sansu/g2/curriculum/*.svg` は全16ファイルを今回の課題用に座標から新規制作。矩形、直線、円、文字のみ。時計の長針・短針は時分から角度を算出。図の分割・方眼・テープは数値関係と一致させた。教科書画像・文言・写真をコピーしていない。既存 `visuals/{milk-large,milk-school,juice-can,small-bottle}.svg` は原創図形を保持し容量ラベルを追記。

教員の正式承認タグは付けていない。既存取込コンテンツの公開権利審査は従来のhold扱いを維持。新規16SVGは親担当が権利台帳へ登録し、統合後にmanifest/catalogを再生成する。
