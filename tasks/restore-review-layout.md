# 問題レビューの周辺レイアウト復元

ユーザー指定により、周辺UIを全体の割合拡縮導入直前（c7354f70、11月4日夜）のCSSへ戻す。復元対象は文字・余白・左一覧幅・狭幅の列切替。現在の単元名→赤い❌→件数の横並びは現行DOMに対応した固定サイズで保持する。問題内の共通viewportによる見切れ防止と選択肢上限8個は変更しない。

回帰防止は1280/1600/1920pxで一覧幅440px・入力文字16px・操作文字16pxを検査し、820px前後の列切替と問題内のクリップ検査を維持する。以前の「画面全体の倍率を固定」検査とルールを現在の要件へ置き換える。

旧版に含まれていた検索一覧の無制限な縦伸びは再導入せず、全画面幅で520pxを上限として一覧内スクロールを維持する。

## 確認結果

- check:fast、typecheck:tests、build成功。
- 一覧・8択・問題内縮小のE2E53件成功。Android相当16件成功（1280/1600/1920pxの一覧幅、820px前後の切替、回転、入力、検索内スクロールを含む）。
- アプリ内ブラウザで単元一覧と問題を目視確認。GraphifyでQuestionTreeの参照元を確認し、コードのみのグラフを更新した。
- 自己レビュー: 復元元CSSとの差分を、現在の単元行と検索の高さ上限に限定。問題レンダラー・8択の契約・削除処理・教材データを変更していない。
- 実機スマホとiPhone相当は未確認。iPhone検証用WebKitは前回起動障害が発生している。
