# Implementation Plan: 場面別BGM

承認済み仕様: `SPEC-game-music-system.md`。2026-10-12の「おけ」を受けて実装する。

## 構成

- Scene単位の音楽セッションを重ね、最上位だけを再生する。戦闘終了で下の探索曲を同じ再生位置から復帰する。
- HTMLAudioElementを使用し、短いフェード、ユーザー操作後の再試行、音量変更を共通実装する。
- マップ種別から曲を選択し、同じ曲のマップ間移動では位置を引き継ぐ。
- 勝敗の確定時にループを専用ジングルへ置き換える。
- 既存通常戦闘曲を保持し、8音源をStable Audio 3 MLXでローカル生成する。
- 関連する権利台帳、音声数の監査、資産カタログを更新する。
- 大量の既存差分を保持し、Sceneの変更を接続箇所に限定する。コミット、push、mergeは今回行わない。

## 注意点

- タイトルの初回はユーザー操作前なので、ブラウザの自動再生制限に従い操作後に開始する。
- 勝敗ジングル終了後は結果画面で無音を保ち、フィールドへ戻る時点で探索曲を再開する。
- 他の作業が進行中なので、全体検査の結果は実行時点の作業ツリーに対するものとして記録する。
