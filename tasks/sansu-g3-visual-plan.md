# 小3算数の視覚化

基点 `5eac0a76`、専用ブランチ `codex/math-fruit-pictogram`。
ユーザーの「小3も同じように」の継続指示に基づき、小1・小2と同じ教材改善を実施する。

## 仕様・デザイン基準

340問を監査し、具体物・分け方・分数・小数・時刻・測定・文章題の理解を補助する。
小1・小2の自作教材図、既存の時計とものさし、Refero craft-detailsを参照元として固定。
白地・濃い線・等間隔を用い、色だけに頼らず数量と関係を伝える。
本文にある既知の値だけを表示し、未知の値は「？」にする。代替説明も追加。
ID・学年・単元・タイプ・隔離状態と学習目標を維持する。棒グラフなど元の学習表現を保つ。
分数6問は旧カンマ区切りが38などの整数として採点されていたため、解説に基づき入力を修正。
5問を分子・分母の2欄とし、4/7+3/7は解説どおり整数1を正解にする。その他の正解は維持。
不足した原資料や正解と解説の不一致は、推測で直さず全問監査に記録する。
バナナの問題は解説の「4本入りの袋を作る」という条件を明示し、正解7袋を維持する。
