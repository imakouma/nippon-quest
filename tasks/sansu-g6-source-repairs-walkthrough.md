# 小6の残り21問の修復

193問中の保留21問を照合し、20問の欠落条件・帯分数表記を復元して20枚の教材図を追加した。代表値の語句問題1問は元々成立しており、問題を変えず監査の誤判定を訂正。小6は114問を今回までに図示、61問は既存図、18問は数式・語句練習となった。小1〜小6の追加図示は合計608問。

分数6問は分子・分母を2欄に分けた。対称と体積の3問は欠けた2つの空欄を戻し、選択肢をすべて2語にそろえた。比例・反比例は長さ・面積・重さ・距離の条件を復元。帯分数3問の解説で表示されていた未対応のcancelコマンドを、通常の分数式に書き直した。正解の数学的な値、問題ID、単元、保存形式は維持している。

## 照合と画像の由来

`imports/legacy-questions/staged.json` のnodeId/sourceIndex → 旧プロジェクトの `src/lib/mathGrade6EboardQuiz.ts` → `scripts/importGrade6EboardQuizzes.mjs` が参照するローカル収集データ `questions.json` の順に追跡。保存されていたqtext_template・解説・正解を確認した。各問のcontentId、subSectionOrder、questionNumber、questionIdは `scripts/data/sansu-g6-source-repairs.json` に記録している。

元データから数値・式・条件を確認し、問題文は現在の形式で書き直した。元サイトの画像を複製せず、既存の自作SVGヘルパーとアイコンで新たに作図している。元データファイルやローカルの絶対パスは配信しない。
