# 小2〜小6 算数レビュー

ユーザー承認範囲：各学年を小1と同じ手順で全件確認し、学習指導要領と東京書籍・啓林館の公開年間計画を比較する。式・答え・図・解説の破損を原資料で修復し、不足領域には独自問題と解説を追加する。教科書ごとの順序差は監査記録へ残す。

## 分担と影響範囲

- 学年担当5名：専用worktreeのg2〜g6問題・SVG・順序JSON・図監査台帳・学年別テスト・出典付き監査記録。実行枠の上限により3名ずつ開始。
- 親：mathReviewOrder / MathReviewFolders / QuestionTreeと共通テスト、生成manifest/catalog、権利台帳、CI、統合調整。
- 既存問題IDと保存フォルダを保持。学習順scopeに学年を含め、同名グループの混同とaria ID重複を防止する。ゲームのカリキュラム契約は変更しない。

## 完了条件

1. 全学年の現行問題が学ぶ順に重複なく収録される。
2. 出題に必要な情報と正答・理由のある解説を確認し、復元できないものは明示する。
3. 指導要領・公開計画との対応と不足補強の理由を記録する。教科書の文言・図の複製や教員承認の代用はしない。
4. 関連unit/E2Eで学年分離、既存フォルダ非破壊、正答・解説・画像と画面幅を検証。
5. 統合担当が統合後の完全ゲートを実施し、正規4174のroot/headを確認して右側の「問題レビュー」に表示。
