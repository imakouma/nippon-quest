# Implementation Plan: 探索の効果音

ユーザーの「BGM関係をpushし、その後主人公が歩く音などの効果音を追加する」に対応する最初の探索音セット。

## 仕様

- 足音4種（草・砂・石・水辺）と、扉・宝箱をStable Audio 3 Small SFXで無料ローカル生成する。
- 草・森・畑は草、海浜は砂、水辺は浅い水、山・町・ダンジョン・裏ステージは石。既存の地面判定を使う。
- 一歩の移動完了時に一回だけ鳴らす。立ち止まり、壁への衝突、会話、戦闘中には足音を起動しない。
- 足音は連続歩行の負担を抑える小さい音量。連続移動時の再生間隔は160msで、音源は短い単発音へ切り出す。
- 町・ダンジョン・裏ステージへの入口/出口だけで扉音を鳴らす。地図ワープ・船・敗北帰還には扉音を重ねない。
- 宝箱を初めて開く時に開封音を鳴らす。空箱の再確認では鳴らさない。特産品の発見ジングルは保持する。
- 既存のWeb Audio SE処理を再利用し、6音源を先読み・デコードして一歩ごとのHTTP要求を避ける。
- 読込未完了の足音を後から遅れて再生しない。音源読込失敗はゲームを止めない。
- 既存の `seVolume` とミュートを使用し、音量変更を実行中のSceneへ反映する。
