# 漢字問題の全学年展開 完了記録

## 完了した内容

- 小学1〜6年の教育漢字1026字を正規データ化した。
- 各漢字について、書き・音読み・訓読みを1問ずつ生成し、合計3078問を収録した。
- Playgroundの漢字フォルダを、読み（音読み・訓読み）／書き／その他（四字熟語・対義語・類義語）へ整理した。
- 書きは単元フォルダを挟まず問題を直下表示する。
- 分類不能な既存の漢字問題は「その他」に残し、他教科や漢字以外の単元は混ぜない。
- 空のフォルダ構成API応答で内部JSONエラーを表示しない。
