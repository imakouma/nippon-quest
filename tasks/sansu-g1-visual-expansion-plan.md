# 小1算数の視覚化（果物問題の続き）

基点: `4167704b`、ブランチ: `codex/math-fruit-pictogram`。
ユーザーの「他の小1の算数も同じように画像を入れる」という継続指示を対象とする。

## 目的・完了条件

小1の全186問の本文・選択肢・既存画像参照を調査し、対象一覧を残す。
物の数・増減・対応・順序・形・位置・比較・10のまとまり・文章題を、同じ間隔の絵と簡潔な図で説明する。
数える対象を具体物に置換する場合は本文と解説も一致させる。
単純な式の反復練習、数字列の穴埋め、既に適切な図や操作がある問題は維持する。
学年、単元、問題ID、正解の内容は維持。計算結果を図に印字しない。

## デザイン方針

前回の果物の絵グラフを基準に、既存の果物・動物ドット絵と独自の単純な教材図を使う。
白い図面、濃い文字、同サイズの具体物、同じ起点・間隔、明示的な取消線や囲みを使用。
Refero craft-detailsと既存の時計・表図版を補助参照。外部検索・外部画像送信なし。
物の数は色だけに頼らず、個々の形で数えられるようにする。装飾画像だけの追加はしない。

## 実装順と検査

1. 数える・増減・対応・位置・形の図を作成し、既存のpromptImage/choices.imageへ接続。
2. 10のまとまりと文章題に、まとまり・差・配分前の具体物を表す図を追加。
3. 対象一覧と正解維持・図版整合のテストを作成。全対象を4サイズで描画監査。
4. `pnpm check:fast`、関連Vitest、代表E2E、`pnpm test`、`pnpm validate:content`、`pnpm build`。
5. アプリ内ブラウザの「問題レビュー」で複数種類を操作し、狭幅・通常幅・正答・解説を確認。

## 変更範囲・境界

教材JSON、`assets/questions/sansu/g1/visuals/`、図版生成スクリプト、対象監査一覧、テスト。
画像表示は既存のchoice/text-input機能を再利用。問題契約・スキーマの変更、依存追加なし。
画像非対応の数入力モードは、必要な1問のみ既存text-inputへ切替え、正答値は維持する。
無関係な別チャットの計画・作業ツリー・共有ブランチには変更を加えない。
