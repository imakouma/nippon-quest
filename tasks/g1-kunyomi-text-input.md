# 1年生の訓読みを例文付き入力に変更

- 基点: 共有main `4d4a1c30`。ブランチ: `codex/g1-kunyomi-text-input`。
- 対象: 小1訓読み80問。既存ID・漢字・単元・タグ・件数を保ち、小2以降の訓読みと音読みデータは変更しない。
- 音読みと同じ表示部品・ひらがな入力検証をそのまま使用。UI実装・契約/schema・依存の追加はしない。
- 例文には問う漢字だけを一字残す。送り仮名は既存templateで入力欄の外に置く（「休む」→「やす」＋固定表示の「む」）。強調範囲と正解範囲を一致させる。
- 入力文字と送り仮名を合わせて正規読みと照合する独立監査を追加。訓読みが複数ある文字では「三つ」「六つ」「天のがわ」「入る」など例文に自然な読みを選ぶ。
- 生成元: `content/kanji/g1-kunyomi-contexts.json`。正規読みは既存 `content/kanji/readings.json`。例文は新規作成。
- 用語確認: [字（あざ）／漢字ペディア](https://www.kanjipedia.jp/kotoba/0002843700)、[千草／imidas広辞典](https://imidas.jp/kojiten/detail/W-17-0-120-06.html)、[本の用例／ぷりんときっず](https://xn--fdk3a7ctb5192box5b.com/pdf/es/jp/kanji/kanji_1_all_h.pdf)。
- 検証: 先に5ケースの再現テスト失敗を確認→生成処理と監査を修正→関連テスト29件成功。全体ゲート、4幅で正答/誤答/案内表示、送り仮名の画面を確認後、共有版へ統合し正規プレビューを更新する。

## 検証結果

- `pnpm check:full`: lint、依存境界、各教材監査が成功。全2414単体テストのうち2413件成功、無関係な地形描画の `viewTiles` 1件が15秒で時間切れ。単独再実行では8秒で成功。
- 残りのゲートを継続実行し、教材検証、学習グラフ検証、全型検査、開発ツール付きbuildが成功。
- 最後の性能予算のみ既存の容量上限超過で失敗（content bundle 4,661,682 bytes > 4,000,000 bytes）。上限は変更しない。
- Playwright: 音読み/訓読みの各4幅、送り仮名、長文レイアウト、IMEの計11件成功。案内表示/正答/誤答/Enter操作説明の非表示も検証。
- 80問のID・タグ・単元・対象漢字を変更前と比較して維持を確認。自動監査が更新した無関係なレポートは除外。
- 画面: [訓読み](../test-results/g1-kunyomi-1440.png)、[送り仮名](../test-results/g1-kunyomi-okurigana.png)。
- コードレビュー: 既存レンダラーを再利用し、変更は生成元・生成処理・独立監査・テストに限定。保存/シーン/型契約への変更なし。
- 実機スマホと教材の人による学術承認は未実施。
