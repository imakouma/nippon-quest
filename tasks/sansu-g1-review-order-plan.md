# 小1算数レビュー 学習順の整備

ユーザー承認済みの教材レビュー（2026-11-16）に従う最初の変更。

## 仕様・範囲

- 小1算数に読み取り専用の「学ぶ順」を追加。基礎35問を対応、1〜5、6〜10、数の順序、何番目、合成分解、10づくりに分類する。
- 残りは基本加減、20まで、繰り上がり・繰り下がり、大きい数等へ段階分け。資料は東京書籍・啓林館の令和6年度年間指導計画。唯一の全国共通順とはしない。
- 問題ID/unit/教材内容と保存済みフォルダ構成を変更しない。既存フォルダ管理は「単元・保存フォルダ」で残す。学ぶ順からのフォルダ移動操作は出さない。
- 全189問を重複なく収録。未分類の新規問題も見失わない。式欠落13問は修復待ちに表示。
- 形式確認と学術的承認を区別する表示にする。contracts/schema変更・新依存・本編の出題順変更はしない。
