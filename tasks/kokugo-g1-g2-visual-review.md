# 小1・小2 国語の視覚補助

対象は両学年の全 1,099 問。文字の読み・書き・字形を学ぶ漢字問題も含めて分類し、34 問に 18 点のオリジナル SVG を追加した。残り 1,065 問は文字の比較・文法・本文の読解を保つ。

## 選定と表現

- 文法・助詞: 文中の犬、小鳥、読書、学校への移動、文房具、雨、花、笑顔を図示する。文のどの部分が主語・述語か、空欄の助詞は図示しない。
- 原稿用紙: 空のマス目を表示する。最初に書くマスは示さない。
- 表記: 切手・服・乗り物の形を示す。カタカナの正答を画像・説明・title に書かない。
- 言葉遊び: 元の「りんご」から空欄へ向かう図、元の順序の「い・か・す」カードで操作対象を示す。後続語や並べ替え後の語は描かない。
- 読解: 場所・理由・順序・気持ちを答える問題は、答えになる情景図の追加を避ける。

図は 480 × 220、文字は 30px 以上、線幅は基本 3px。短い絵の説明を読み上げに加える。各問の判断は `scripts/data/kokugo-g1-g2-visual-review.json` に記録した。

## 検査

- 生成スクリプトを実行し、34 問 / 1,099 問、正答・選択肢・ID・型・学年・単元の不変条件に合格。
- 基点との JSON 比較で、34 問の画像・読み上げ以外のフィールドがすべて不変であることを確認。
- 生成スクリプトの ESLint / Prettier、tools TypeScript 検査に合格。
- 全件品質ゲート・スマホ表示・画像の実描画・本番反映は統合担当で実施する。
