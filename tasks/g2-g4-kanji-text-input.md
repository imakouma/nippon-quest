# 2〜4年生の音読み・訓読みを例文入力へ

## 仕様と範囲

- ユーザー指定の1年生と同じ形式を2〜4年生の音読み・訓読みに適用する。
- 各分類の問題数（160・200・202）とID、単元、タグを維持する。
- 例文中の対象漢字一字を読み、ひらがなで入力する。送り仮名は入力欄の外へ表示する。
- 正規漢字データにある読みを使用し、対象以外の文字はかなで表記する。
- 既存の読み入力UI・IME対応・不正文字時のみの案内を再利用する。
- 1年生と5〜6年生、書き取り、契約/schemaは変更しない。

## 実装・検証計画

1. 全学年/分類の入力形式、正規読み、送り仮名、保存ファイルを検証するテストを追加。
2. 学年/分類別の例文を用意し、既存の生成・独立監査を1〜4年へ拡張。
3. 内容全件監査、関連テスト、ブラウザで各学年/分類の採点・狭い画面を確認。
4. 差分レビュー後、共有版へ統合し、統合状態で完全検査。4174の問題レビューを開く。
