# Walkthrough: 学習ロードマップの7項目改善

## 実装結果

1. 単元選択は現在の地図位置を維持し、画面外の単元だけ24px余白内へ最小パンする。
2. 19段階スライダーを削除し、学年7択とおすすめ時期4択の48pxボタンへ変更した。
3. 教科タブは全学年で「全教科・国語・算数・理科・社会・生活科・英語」の全文表示にした。
4. 前線単元は地図と詳細の両方で実名を伏せ、前提単元をボタンで選択できるようにした。
5. 全教科概要の先頭に、黄色の「つぎのおすすめ」主要行動を追加した。
6. 常設ズームツールは戻さず、アプリセッション内の初回だけジェスチャー説明を表示し、操作開始で消すようにした。
7. 時期説明を48pxの開閉ボタンにし、単元ノードの `aria-pressed` を廃止して通常ボタンとして選択状態を読み上げるようにした。

## Visual QA

- 960×540: 学年・時期・全文教科タブが重ならず、概要のおすすめ、2列カード、地図、選択詳細が収まる。
- 640×540: アプリの既存スケーリング下で、教科タブと概要が操作可能なまま表示される。
- ロック詳細: 実名を公開せず、前提単元名・達成状態・移動操作を表示する。
- ジェスチャー説明: 地図左下へ置き、主要ノードと開始ボタンを塞がない。
- 既存の濃紺、硬いピクセル枠、黄色CTA、教科色を維持し、汎用管理画面風の見た目は追加していない。
