# 小6算数の視覚化と本番統合

基点 `e5aabc2b`、作業ブランチ `codex/math-fruit-pictogram`。
ユーザーの「小六もラスト進めて、それが終わったら本番にマージ」の指示に基づく。

193問を全件確認し、対称・文字式・分数・比・縮尺・円と柱・資料・比例と反比例・場合の数に必要な図を追加する。
小1〜小5の教材図とReferoの既存参照を使い、同じ大きさの全体、量に対応する寸法、濃い輪郭、読み上げ用説明を保つ。
選択問題で正解だけを図示しない。未知の答えは図に印字しない。欠落や不整合は推測で補わず監査に記録する。
分数の式・解説・正解が一致する問題では、連結された分子と分母を別々の入力欄にする。

変更先は小6教材、SVG、生成スクリプト、全問監査、既存の画像CSS、単体・表示検査、制作根拠とカタログ。
スキーマ・依存・保存形式は変更しない。既存の別チャットの作業や入力欄改善を保持する。

単体・4サイズE2E・実画面確認後に小6をコミットする。
本番 `imakouma/nippon-quest` の最新mainを取得し、小1〜小6の変更を統合する。
統合後に必須ゲートと関連表示検査を実行し、PR・CI・マージまで進める。
公開先に配信ジョブがある場合はその結果を確認し、正規4174プレビューを統合済みコードから起動する。
