# 県地図の段階的詳細化 — 実装計画

## 目的

左上の県ミニマップを一回り大きくし、県地図を拡大したときに単色ドットの引き伸ばしではなく、フィールド本編と同じタイル絵由来の細かな地形が見えるようにする。

## 設計判断

- 既存のピンチ、トラックパッド、ホイール、ドラッグ操作と最大3倍のズーム範囲は維持する。
- 県地図の表示モデルやセーブデータは変更しない。表示層だけで、ズーム量に応じて地形キャンバスを再描画する。
- 等倍では従来の軽量な1ドット地形、1.5倍付近では4倍、2倍以上では8倍の描画密度を使う。
- 詳細描画はフィールド本編の16pxタイルセットを縮小して使い、道・森・山・砂浜・水辺などの模様を追加データなしで一致させる。
- ロック中の範囲は従来どおり詳細を伏せる。

- [x] 1. 描画密度がズームに応じて上がる失敗テストを追加する。
- [x] 2. ミニマップを一回り拡大し、画面内に収まることを固定する。
- [x] 3. フィールドタイルセットを再利用した段階的詳細描画を実装する。
- [x] 4. 対象E2E、全品質検査、実ブラウザ確認を行う。
- [ ] 5. 最新 `main` へ統合し、本番デプロイと本番画面を確認する。

## 完了条件

- ミニマップの表示領域が144pxから168pxへ広がる。
- ズーム1倍では地形キャンバスが1マス1画素、1.5倍では1マス4画素、2倍以上では1マス8画素になる。
- 最大ズームでフィールドタイル由来の内部模様が見える。
- 操作、ワープ、周辺県の暗い表示、未解放範囲の秘匿に回帰がない。
- 必須検査と本番デプロイが成功する。
