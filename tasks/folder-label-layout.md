# 単元名の1文字ずつの折り返しを解消

削除ボタン用の右余白と問題数が単元名の表示幅を圧迫していた。単元名をボタン全幅へ広げ、問題数と削除ボタンを通常フローの下段へ移す。負のmarginによる重ね配置を廃止する。問題数はaria-describedbyで単元ボタンに関連付け、選択・削除処理、2列/スマホ縦1列、連続倍率は維持する。

修正前は1行あたり1.59文字の幅になり、回帰テストで失敗を再現。390/768/1440pxで5文字分以上の横幅と2行以内、件数・削除ボタンが重ならないことを確認。Playground E2E36件成功。アプリ内ブラウザで国語→小1を開いて確認。

前回PRのCIで別の既存レイアウト監査テストにResizeObserver待ち不足が判明したため、高さ0から復元した後は描画が正常化するまで待ってから文字クリップを検査するよう修正する。製品の挙動変更はない。

最終検証: check:fast・typecheck:tests成功。ビルド成功。修正2テストはビルド済み配信で各3回（計6件）成功。独立レビューの必須指摘なし。確認画面は国語→小1を開いた状態で提示する。実機スマホは未検証。
