# 技の命中率・追加効果 実装計画

基点: 統合ブランチ `codex/publish-problem-review-20261116` の 6b47e4a4535028e997016e59f6a98195b0925da7。仕様: `SPEC-skill-accuracy-effects.md`。

## 変更理由と影響

全技で命中率と追加効果を設定するには技データのZodスキーマ `src/core/content/schemas.ts` と生成JSON Schemaを拡張する必要がある。ローダー、コンテンツ検証、既存の技データ・テストに影響する。既存技には命中率100%を明示し、未追加効果はなしとして互換性を維持する。生成物は `pnpm gen:schemas` で生成する。質問契約は変更しない。セーブ形式と中断戦闘の互換性を維持する。

## 実装順と確認

1. データと判定：命中率の範囲検証と0%・100%・中間確率のテストを先に追加。共通の命中判定を主人公、敵、仲間の技に適用し、外れをイベントとして表現する。ゲージ・MP・回答結果の扱いと乱数の再現性を検査。
2. 追加効果：攻撃・防御の上昇／低下、対象、確率と持続の検証を先に追加し、既存バフ処理を活用。命中失敗、戦闘終了、複数回の使用と敵・仲間の行動を検査。代表的な既存技に効果を設定する。
3. 表示と確認：技一覧に命中率と効果、戦闘中に外れと能力変化を表示。翻訳データを使い、既存のイベント表示を通す。関連ユニットテストとブラウザで確認する。
4. 全体検証：`pnpm check:fast`、関連テスト、`pnpm lint`、`pnpm check:architecture`、`pnpm test`、`pnpm validate:content`、`pnpm build`。他チャットの重い検査との重複を避ける。失敗や未実施は明示する。

## 別途扱う機能

主人公の通常技4枠・チャージ技2枠、既存セーブ移行、バーストと装備の扱い、編成UIは後続の仕様・計画として行う。仲間の技は主人公の枠に含めない。技管理画面と全技の大規模バランス調整は別工程。
