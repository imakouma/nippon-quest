# 小2算数の視覚化

基点 `57b00fe3`、専用ブランチ `codex/math-fruit-pictogram`。
小1で実施した改善を小2にも適用する、というユーザーの継続指示に基づく。

## 仕様・デザイン基準

小2算数320問を監査し、具体物・量・まとまり・比較・形・時間の理解を助ける画像を追加する。
小1の教材図、既存の時計・ものさし画像、Refero craft-detailsを参照元として固定する。
白地・濃い線・同じ間隔・意味のあるまとまりを使い、色以外でも数と関係を判断できるようにする。
本文にある既知の数だけを図に表示し、未知の値は「？」にする。読み上げ用説明も追加する。
ID・タイプ・学年・単元・正解・隔離状態は維持する。既存の十分な画像と記号の読み取り練習は維持。
元の式や条件が欠ける問題は推測で再構成せず、原資料の確認対象として監査一覧に残す。

## 範囲・実装順

- [x] 320問の本文・テンプレート・選択肢・画像を調査し、全問の判断理由を記録。
- [x] 時計・かさ・長さ・具体物のまとまりを既存のpromptImage/choices.imageに接続。
- [x] 位取り・文章題・形の図を追加。必要なCSSは小1の図の表示ルールを小2へ拡張。
- [x] 正解維持・画像整合・代替説明・全対象の4サイズ描画を検査。
- [x] 問題レビューで実操作・通常幅と狭幅・コンソールを確認し、記録してコミット。

教材JSON → 既存レンダラー → 共通viewportの依存方向は変えない。
変更先は小2教材、SVG、再生成スクリプト、監査一覧、CSS、検査、制作根拠と生成カタログ。
スキーマ変更、依存追加、セーブ変更、外部画像生成・アップロード、共有ブランチへの統合は行わない。

`pnpm test`、`pnpm validate:content`、`pnpm build`。
