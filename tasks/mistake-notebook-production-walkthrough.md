# まちがいノートの本体組み込み

フィールドメニューの「まちがい」から相棒の入口、教科の扉、日付で探す旅手帳に進む。
正解した問題は押印待ちとして保存する。押印は既存のセーブ経路で保存し、問題ID・日付・位置・16ビットの種から印を再描画する。
カード12枠ごとの閲覧、押印済みの問題の解き直し、3・6・12個での報酬を追加した。
過去の間違いは解答履歴から日付を取得し、取得できない問題は日付不明として解き直せる。

交換係の担当チャットは、`reviewCardExchangeRewards` と `availableReviewCards` を使用する。
NPCの交換時に `learning.redeemedReviewCards` の更新とアイテム付与を一緒に保存する。
交換係の配置と実際の交換操作は担当ブランチで検証する。

ブラウザ検査は旧形式の保存からゲームを再開し、フィールドメニュー、国語の一覧、問題への正解、手押し、問題記録への復帰、再読み込み後の保存確認を通す。
検査の最終画面は Playwright 出力の `review-stamp.png` に残る。
