# 1年生の音読みを例文と文字入力にする

## 仕様と担当範囲

- 対象は1年生の音読み80問。例文の対象漢字一字をひらがなで入力する。
- 先頭問題は「一ばんおいしいパン」、正解は「いち」。「ひと」「いちばん」は誤答。
- 対象漢字にふりがなを出さず、ほかの語はかなで書く。
- 既存の問題ID、単元、学年、タグ、問題数を保持。2〜6年の音読みと全学年の訓読みは維持。
- 既存 text-input を利用。文字回答時は文字キーボードを要求し、IME変換確定Enterでは送信しない。
- 契約、スキーマ、保存形式、依存関係は変更しない。

## 実装順と確認

1. 期待する例文・入力・採点・IME動作の失敗テストを確認。
2. 例文JSON、再生成処理、教材監査を更新し、1年生の3セットのみ差分を作る。
3. 関連単体テスト、`pnpm check:fast`、ツール・テスト型検査、漢字問題監査を実行。
4. ブラウザで正答・誤答と320/768/1024/1440pxを確認し、初期状態のプレビューを表示。
