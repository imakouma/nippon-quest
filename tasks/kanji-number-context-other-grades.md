# 他学年の漢字読み問題：数字の表記

## 対象と判断

- `codex/kanji-number-context` で作業。前回の１年「１０円」を保持し、２〜４年の例文入力式が統合された `b02ab170` を取り込んだ。
- 担当範囲は、漢字読み問題の例文・解説とその生成元だけ。出題対象、ID、読みの正解、送り仮名、採点処理は変更しない。
- 回数・数量・順位・時刻を表す数字は全角算用数字にする。「さん角」「いち期いちえ」など熟語の一部や「ふたり」のような自然な語形は一律変換しない。
- 「以」の例文は期間が明確な「１じかん 以ないに おわる」にする。「兆」は他の大きな数の読みを重ねない「１兆の かずを かく」にする。
